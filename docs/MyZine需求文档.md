# MyZine 需求文档（给 AI 的开发提示词）

> 更新：2026-10-17。阶段 1–5 已完成。新增「阶段 6 详细需求」：设计引擎升级、纯色系列、3 个招牌风格。

我要开发一个微信小程序「MyZine」，把用户的旅行照片做成好看的照片书。项目已用微信开发者工具的「JS 基础模板（不使用云服务）」创建好，请在此基础上开发。

## 技术约束
- 原生微信小程序 + JavaScript，默认 WebView 渲染（不用 Skyline），画布用 canvas type="2d"
- 纯本地：不发起任何网络请求，不登录，不用云开发，所有素材打包在代码里
- 主包控制在 2MB 以内，风格素材按风格放进分包
- 代码注释用中文

## 页面规格（固定，第一版只支持这一种比例）
- 页面比例 3:4
- 基准画布：单页 1080×1440，跨页 2160×1440（版式坐标用 0–1 比例存储，设计按此尺寸）
- 安全边距：四周约 72px（5%），文字和重要元素不超出
- 中缝：跨页中间左右各约 40px 为书脊区域，单页版式的照片框不贴中缝；跨页大图在编辑时显示中缝参考线

## 用户流程
1. **填写书籍信息**（全部选填）：书名、作者、同游人、旅行地点、旅行日期、想说的话
   - 编辑过程中随时可以从编辑页进入修改，修改后封面和扉页立即更新
2. **导入照片**：用 wx.chooseMedia，单次最多选 20 张，可多次追加，总数不限
   - 界面明显提示「继续添加」
   - 导入后可删除、继续添加、拖动调整顺序
   - 照片顺序 = 用户选择顺序
   - 编辑和预览使用压缩版（长边不超过 2048），同时保留原图临时路径，供打印版导出使用
   - 导入时用 wx.getImageInfo 读取宽高，按宽高比分类：横图（> 1.1）、竖图（< 0.9）、方图（其余）
3. **选择一套主模板**（即一种风格）
4. **自动排版**：生成封面、扉页、正文页、封底，照片按顺序填入正文页
   - 正文版式轮换使用（单图、双图、三图等交替），避免单调
   - 按方向匹配：根据接下来几张照片的方向，优先选择照片框方向一致的版式（横图进横框、竖图进竖框），在匹配的版式中轮换
5. **编辑**：
   - 一屏编辑一页
   - 点击照片框，弹出照片选择面板，可替换为任意已导入照片
   - 选择面板规则：
     - 已使用的照片在缩略图右上角显示所在页码标签，如「P3」
     - 同一张照片允许多次使用，标签显示「P3 P8」
     - 未使用的照片正常显示，已使用的不变灰
     - 当前照片框中的照片加高亮边框
     - 顶部有「全部 / 未使用」筛选
   - 调整照片在框内的显示（见下方「照片比例处理」）
   - 可更换某个跨页的版式
   - 可更换某个跨页的模板（实现混搭，比如风景页用胶片风、美食页用手账风）
   - 页数不限，可增加、删除跨页，调整跨页顺序
6. **预览**：双页展开，封面单独在右侧，正文两两成对，封底单独在左侧，左右滑动翻页
7. **导出**（见下方「导出」）

## 照片比例处理
- 照片绝不拉伸变形
- 默认「填满」：照片等比放大到填满照片框，超出部分裁掉，居中对齐（aspect-fill）
- 可切换「完整」：照片等比缩小完整放进框内，空白处用当前风格的背景色或白边填充（aspect-fit），适合截图、9:16 等极端比例
- 手动调整：点照片框进入调整模式，单指拖动改变裁切位置，双指缩放（最小为刚好填满框）
- 每个照片框单独保存：照片 id、显示模式（填满/完整）、偏移量、缩放比例
- 更换照片后，裁切位置和缩放重置为默认居中

## 导出
- **主要方式：导出 PDF 相册**，整本书按页序生成一个 PDF 文件
  - 两种清晰度供用户选择：
    - 分享版：每页 1080×1440，文件小，适合手机查看和转发
    - 打印版：每页 2480×3307（约 300dpi，对应 21×28cm），适合打印和冲印；照片从原图读取
  - 生成方式：每页用 renderPage 画到离屏画布 → 导出 JPG → 读取为二进制 → 用自写的轻量 PDF 生成器把所有 JPG 拼成 PDF（每页一张图，DCTDecode），写入 wx.env.USER_DATA_PATH。不依赖浏览器环境的 PDF 库
  - 逐页生成，生成完一页立即释放画布和图片，避免大尺寸时内存不足；显示生成进度
  - 交付给用户：优先用 wx.shareFileMessage 发送到微信聊天（如文件传输助手）；同时提供 wx.openDocument 打开预览。两种方式都要真机测试
  - 文件名使用书名，书名为空时用「MyZine相册_日期」
  - 导出完成后清理临时文件
- **次要方式：保存为图片**，用于发朋友圈、小红书
  - 可选择全部页或指定页，单页 1080×1440 保存到相册；可选按跨页导出（2160×1440 横图）
  - 保存相册时处理用户拒绝授权，用 wx.openSetting 引导开启

## 信息显示位置
- 封面：书名（大字）、旅行地点 + 旅行日期、作者（小字）
- 扉页：作者、同游人、想说的话、旅行地点和日期
- 字段为空时自动隐藏对应元素，排版不留空洞

## 模板架构：版式 × 风格
- **版式（layout）**：定义页面类型和照片框位置，坐标用 0–1 比例，支持圆角、旋转、边框
  - 每个照片框标注方向（横 / 竖 / 方），供自动排版匹配
  - 页面类型：封面、扉页、正文、封底
  - 正文版式成对设计（左页 + 右页）：单张大图、双图、三图、四图、图 + 留白、跨页大图；同一张数提供横框和竖框的不同组合
- **风格（style）**：定义配色、字体、背景（纯色或纹理图）、装饰元素、照片边框样式
  - 风格分三组：
    - 纯色：纸白、燕麦、雾灰、雾霾蓝、鼠尾草、深蓝、墨绿、酒红
    - 风格：杂志、手账、胶片、独立 Zine、票根邮戳、拼贴剪报、复古港风、日系清新、黑白
    - 主题：每个主题一套专属配色 + 线稿 + 标志性照片框 + 装饰词（如海边明信片、美食餐桌、公路旅行等）
- **适合主题（标签）**：每种风格标注适合的内容主题，首页可按风格或按主题筛选
  - 主题列表：自然风光、人文建筑、美食、聚会、海边海岛、城市夜景、公路旅行、亲子家庭、情侣纪念、萌宠、动物园或农场、游乐园
- 模板 = 某种风格应用到全部版式上。新增风格只加数据和素材，不改代码
- 换模板以「跨页」为最小单位，保证左右两页风格一致
- 能用代码画的（纯色、边框、圆角、阴影、线条）尽量不用图片
- 统一的 renderPage(ctx, page, layout, style, 尺寸) 渲染函数，编辑、缩略图、预览、导出共用，保证所见即所得；所有尺寸按画布宽度等比换算，同一函数可输出 1080 宽和 2480 宽

## 分阶段开发
每完成一个阶段停下来，告诉我怎么测试，等我确认再继续。

- 阶段 1：1 种风格、横框和竖框各 1 种正文版式：导入照片（读取宽高）→ 按方向自动填入（填满裁切）→ 渲染 → 保存单页图片到相册，真机跑通
- 阶段 2：书籍信息填写和随时修改 + 封面、扉页、封底；版式 × 风格数据结构
- 阶段 3：照片选择面板（页码标签、筛选、高亮）+ 照片拖动缩放调整 + 填满/完整切换 + 跨页增删排序 + 双页预览
- 阶段 4：PDF 导出（分享版、打印版、发送到聊天、打开预览、进度显示）+ 图片导出（选页、跨页）
- 阶段 5：全部正文版式 + 3 种风格（胶片、手账、极简）+ 按跨页混搭 + 首页按风格/主题筛选（已完成）
- 阶段 6：设计引擎升级 + 纯色系列 8 种 + 3 个招牌风格（杂志、手账升级、海边明信片），详见下方「阶段 6 详细需求」
- 阶段 7：补齐其余视觉风格和主题风格（总数 20 个以上）、立体翻书展示、退出提示（如尚未实现）、写 README（项目结构、如何新增风格、版式、线稿）

## 阶段 6 详细需求

目标：现在的成品「干净但没有吸引力」。参考优秀照片书，吸引力来自：文字当装饰、版式节奏、照片形状、打破网格、手绘线稿、色块背景。本阶段先把这些能力做进渲染引擎，再用它们做出 1 个纯色系列和 3 个招牌风格。宁可少而精。

建议拆成 6a（引擎能力 + 新版式 + 纯色系列）和 6b（3 个招牌风格 + 模板页分组），各自真机测试后再继续。

### 6a-1 照片形状
- 照片框新增 shape：rect（默认）、rounded、circle、ellipse、arch（拱形，上半圆下矩形）
- 裁切、边框、阴影、点击检测、拖动缩放都要支持这些形状

### 6a-2 装饰文字层
- 版式和风格都可以定义装饰文字元素，类型：
  - headline：大标题（优先用西文字体）
  - kicker：小号字距加宽的大写副标题
  - runningHeader：页眉，带细线，如「{location} · {date}」
  - pageNumber：页码（两位数，如 07）
  - index：照片编号（01、02…），代替图注，不出现假文字
- 支持变量：{title} {location} {date} {year} {month}；变量为空时整条隐藏，不留空洞
- 风格可提供 wordPool（装饰词池），如杂志风「Good Places」「Still Becoming」「Side Notes」「More Good Days」。按跨页 id 稳定选取（同一本书每次渲染结果一致），相邻跨页不重复
- 只对西文做大写变换；中文地点原样显示，不翻译
- 文字位置放在留白区域，不压照片（风格明确设计为压在照片上的除外）

### 6a-3 线稿库
- templates/doodles/：用 SVG 路径数据（含 viewBox）描述线稿，写一个轻量路径解析器在 canvas 2d 上绘制（支持 M/L/H/V/C/S/Q/T/A/Z），描边宽度随画布宽度等比换算，打印版也清晰
- 线稿可设置颜色、描边/填充、缩放、旋转
- 第一批：星星、闪光、爱心、云朵、音符、花朵、枝叶、箭头、波浪线、贝壳、太阳、海鸥、邮戳圆环
- 做一个开发用的线稿预览页（不上线，正式版隐藏入口），一页列出所有线稿，方便我逐个检查效果
- 线稿放在页面的装饰位（角落、页边、留白区），不遮挡照片主体；胶带、邮戳这类故意压在照片边缘的除外

### 6a-4 新版式
在现有版式基础上补充（同样左右页镜像、标注方向）：
- 满版出血：一张照片铺满整页，不留边
- 小图 + 大留白：一张小照片配大标题或页眉，大量留白
- 密集网格：每页 5–6 张
- 大头贴四格条：竖向 3–4 张小方图连成一条
- 叠压：一张照片带白边和阴影叠在另一张上
- 跨中缝：一张照片横跨中缝（只跨一部分），另一侧配小图
- 圆形、拱形照片框的版式各至少 1 个
- 版式新增 density 标记：dense（密集）/ normal / airy（留白）

### 6a-5 版式节奏
- 自动排版在「方向匹配 → 加权轮换」基础上加节奏规则：不连续出现两个 dense 跨页；连续两个 normal 后，有合适照片时插入一个 airy 跨页
- 风格可开启「反色跨页」：偶尔（约每 5 个跨页一次，不连续）把一个跨页换成该风格的深色版本，制造节奏

### 6a-6 色块背景
- 允许版式或风格为左右页分别设置背景色，或在页面上画大面积色块（不只是整页单色）

### 6a-7 西文字体
- 先确认 wx.loadFontFace 加载的字体能否用于 canvas 2d 绘制（iPhone 和安卓都要验证），告诉我结论再继续
- 可用的话，选 2–3 个 SIL OFL 授权的西文字体：一个衬线展示体（杂志标题）、一个手写体（手账标题）、可选一个窄体无衬线（粗标题）
- 字体子集化，只保留西文字母、数字、常用标点，总共控制在约 300KB 以内，放分包，附上授权文件
- 加载失败时退回系统衬线体；导出前确保字体已加载完成
- 中文仍用系统字体

### 6a-8 纯色系列（8 种）

| 名称 | 底色 | 文字 | 点缀 |
|---|---|---|---|
| 纸白（替代原「极简」） | #F7F5F0 | #2B2B2B | #B5835A |
| 燕麦 | #EDE6DA | #3A3530 | #A68A64 |
| 雾灰 | #E4E4E1 | #2F2F2F | #8C8C88 |
| 雾霾蓝 | #D8DEE4 | #2A3440 | #6F8299 |
| 鼠尾草 | #DCE0D5 | #2F3A2F | #7C8A6E |
| 深蓝 | #1F2A3C | #E8E4DA | #C9A96E |
| 墨绿 | #24332B | #E9E6DC | #B8A57A |

- 装饰克制：页眉（地点 · 日期）、页码、点缀色细线，照片是主角
- 深色三种的中缝线、页码等用点缀色（淡金）
- 原「极简」风格的跨页迁移为「纸白」

### 6b-1 杂志风（参考：大标题旅行杂志、留白排版）
- 纸白底，衬线西文大标题（来自 wordPool），kicker 小字，页眉 + 细线，页码，照片编号
- 偏好满版出血、跨中缝、小图 + 大留白版式；开启反色跨页（深色底 + 浅色字）
- 点缀色：低饱和赤陶色块，偶尔出现在页面一角

### 6b-2 手账风升级（参考：剪贴手账、季节主题拼贴）
- 保留纸张纹理、胶带、拍立得白边和随机倾斜
- 加入线稿：星星、爱心、云朵、音符、花朵、箭头、闪光，每个跨页 2–4 个，位置随跨页稳定变化
- 色块：粉、奶油、浅棕在跨页间变化，左右页可以不同底色
- 偏好大头贴四格条、叠压版式；手写体西文标题（如「Good Days」「Summer Travel」「Yum!」）

### 6b-3 海边明信片
- 海蓝 + 沙色配色，波浪线、贝壳、太阳、海鸥线稿
- 明信片照片框：白边 + 右上角邮票框 + 邮戳圆环（圆环内文字为 {location} 和 {date}，为空则只画圆环）
- 航空信封红蓝斜条边框（用在封面或部分跨页的页边）
- 封面或第一个正文跨页的标题：「Greetings from {location}」（地点为空时用「Greetings」）
- 偏好圆形框和满版出血版式
- 适合主题：海边海岛、自然风光、情侣纪念

### 6b-4 模板页分组
- 模板页分三组显示：纯色、风格、主题（主题组阶段 7 补充）
- 纯色组用色块小圆点快速切换，其余用用户照片渲染的示例跨页

### 阶段 6 验证
- 线稿预览页：所有线稿清晰、比例正常
- 每种形状的照片框：裁切、拖动缩放、点击、导出都正确
- 装饰文字：书籍信息为空时整条隐藏；有地点日期时页眉、邮戳正确显示
- 节奏：30 张以上照片自动排版，没有连续两个密集跨页，留白和反色跨页出现得自然
- 字体：iPhone 和安卓上西文标题都用了加载的字体；打印版 PDF 中字体正确
- 8 种纯色和 3 个招牌风格的封面、扉页、正文、封底在编辑、预览、PDF（分享版、打印版）中一致
- 主包仍在 2MB 以内
