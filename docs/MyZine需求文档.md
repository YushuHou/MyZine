# MyZine 需求文档（给 AI 的开发提示词）

> 更新：2026-10-17。导出改为以 PDF 为主；已加入照片比例处理和页面规格。贴纸、文字、章节页、草稿保存暂不做，放到后续版本。

我要开发一个微信小程序「MyZine」，把用户的旅行照片做成好看的照片书。项目已用微信开发者工具的「JS 基础模板（不使用云服务）」创建好，请在此基础上开发。

## 技术约束
- 原生微信小程序 + JavaScript，默认 WebView 渲染（不用 Skyline），画布用 canvas type="2d"
- 纯本地：不发起任何网络请求，不登录，不用云开发，所有素材打包在代码里
- 主包控制在 2MB 以内，风格素材按风格放进分包
- 代码注释用中文

## 页面规格（固定，第一版只支持这一种比例）
- 页面比例 3:4
- 基准画布：单页 1080×1440，跨页 2160×1440（版式坐标用 0–1 比例存储，设计按此尺寸）
- 安全边距：四周约 72px（5%），文字和重要元素不超出
- 中缝：跨页中间左右各约 40px 为书脊区域，单页版式的照片框不贴中缝；跨页大图在编辑时显示中缝参考线

## 用户流程
1. **填写书籍信息**（全部选填）：书名、作者、同游人、旅行地点、旅行日期、想说的话
   - 编辑过程中随时可以从编辑页进入修改，修改后封面和扉页立即更新
2. **导入照片**：用 wx.chooseMedia，单次最多选 20 张，可多次追加，总数不限
   - 界面明显提示「继续添加」
   - 导入后可删除、继续添加、拖动调整顺序
   - 照片顺序 = 用户选择顺序
   - 编辑和预览使用压缩版（长边不超过 2048），同时保留原图临时路径，供打印版导出使用
   - 导入时用 wx.getImageInfo 读取宽高，按宽高比分类：横图（> 1.1）、竖图（< 0.9）、方图（其余）
3. **选择一套主模板**（即一种风格）
4. **自动排版**：生成封面、扉页、正文页、封底，照片按顺序填入正文页
   - 正文版式轮换使用（单图、双图、三图等交替），避免单调
   - 按方向匹配：根据接下来几张照片的方向，优先选择照片框方向一致的版式（横图进横框、竖图进竖框），在匹配的版式中轮换
5. **编辑**：
   - 一屏编辑一页
   - 点击照片框，弹出照片选择面板，可替换为任意已导入照片
   - 选择面板规则：
     - 已使用的照片在缩略图右上角显示所在页码标签，如「P3」
     - 同一张照片允许多次使用，标签显示「P3 P8」
     - 未使用的照片正常显示，已使用的不变灰
     - 当前照片框中的照片加高亮边框
     - 顶部有「全部 / 未使用」筛选
   - 调整照片在框内的显示（见下方「照片比例处理」）
   - 可更换某个跨页的版式
   - 可更换某个跨页的模板（实现混搭，比如风景页用胶片风、美食页用手账风）
   - 页数不限，可增加、删除跨页，调整跨页顺序
6. **预览**：双页展开，封面单独在右侧，正文两两成对，封底单独在左侧，左右滑动翻页
7. **导出**（见下方「导出」）

## 照片比例处理
- 照片绝不拉伸变形
- 默认「填满」：照片等比放大到填满照片框，超出部分裁掉，居中对齐（aspect-fill）
- 可切换「完整」：照片等比缩小完整放进框内，空白处用当前风格的背景色或白边填充（aspect-fit），适合截图、9:16 等极端比例
- 手动调整：点照片框进入调整模式，单指拖动改变裁切位置，双指缩放（最小为刚好填满框）
- 每个照片框单独保存：照片 id、显示模式（填满/完整）、偏移量、缩放比例
- 更换照片后，裁切位置和缩放重置为默认居中

## 导出
- **主要方式：导出 PDF 相册**，整本书按页序生成一个 PDF 文件
  - 两种清晰度供用户选择：
    - 分享版：每页 1080×1440，文件小，适合手机查看和转发
    - 打印版：每页 2480×3307（约 300dpi，对应 21×28cm），适合打印和冲印；照片从原图读取
  - 生成方式：每页用 renderPage 画到离屏画布 → 导出 JPG → 读取为二进制 → 用自写的轻量 PDF 生成器把所有 JPG 拼成 PDF（每页一张图，DCTDecode），写入 wx.env.USER_DATA_PATH。不依赖浏览器环境的 PDF 库
  - 逐页生成，生成完一页立即释放画布和图片，避免大尺寸时内存不足；显示生成进度
  - 交付给用户：优先用 wx.shareFileMessage 发送到微信聊天（如文件传输助手）；同时提供 wx.openDocument 打开预览。两种方式都要真机测试
  - 文件名使用书名，书名为空时用「MyZine相册_日期」
  - 导出完成后清理临时文件
- **次要方式：保存为图片**，用于发朋友圈、小红书
  - 可选择全部页或指定页，单页 1080×1440 保存到相册；可选按跨页导出（2160×1440 横图）
  - 保存相册时处理用户拒绝授权，用 wx.openSetting 引导开启

## 信息显示位置
- 封面：书名（大字）、旅行地点 + 旅行日期、作者（小字）
- 扉页：作者、同游人、想说的话、旅行地点和日期
- 字段为空时自动隐藏对应元素，排版不留空洞

## 模板架构：版式 × 风格
- **版式（layout）**：定义页面类型和照片框位置，坐标用 0–1 比例，支持圆角、旋转、边框
  - 每个照片框标注方向（横 / 竖 / 方），供自动排版匹配
  - 页面类型：封面、扉页、正文、封底
  - 正文版式成对设计（左页 + 右页）：单张大图、双图、三图、四图、图 + 留白、跨页大图；同一张数提供横框和竖框的不同组合
- **风格（style）**：定义配色、字体、背景（纯色或纹理图）、装饰元素、照片边框样式
  - 风格列表：胶片、杂志、手绘手账、极简纯色、复古港风、日系清新、黑白、拼贴剪报、票根邮戳风
- **适合主题（标签）**：每种风格标注适合的内容主题，首页可按风格或按主题筛选
  - 主题列表：自然风光、人文建筑、美食、聚会、海边海岛、城市夜景、公路旅行、亲子家庭、情侣纪念、萌宠、动物园或农场、游乐园
- 模板 = 某种风格应用到全部版式上。新增风格只加数据和素材，不改代码
- 换模板以「跨页」为最小单位，保证左右两页风格一致
- 能用代码画的（纯色、边框、圆角、阴影、线条）尽量不用图片
- 统一的 renderPage(ctx, page, layout, style, 尺寸) 渲染函数，编辑、缩略图、预览、导出共用，保证所见即所得；所有尺寸按画布宽度等比换算，同一函数可输出 1080 宽和 2480 宽

## 其他
- 不做草稿持久化，但用户在编辑页点返回时，用 wx.enableAlertBeforeUnload 提示「退出后当前相册不会保存」
- 按微信隐私协议要求处理隐私授权弹窗


## 版本管理
- 只使用 main 分支，不需要新建分支或 Pull Request
- 不要自行执行 git commit 或 git push。每个阶段完成后，告诉我建议的提交说明，由我在真机测试通过后提交
- 开始较大改动之前，提醒我先提交当前能正常运行的版本
- 提交说明格式：`类型: 中文描述`，类型用 feat（新功能）、fix（修复）、style（样式调整）、refactor（重构）、docs（文档）、chore（配置等杂项）
  - 示例：`feat: 阶段1 导入照片并按方向自动排版`、`fix: 修复大图导出时闪退`
- 需求文档放在 docs/ 目录，需求变更时我会更新它，请以最新版为准

## 分阶段开发
每完成一个阶段停下来，告诉我怎么测试，等我确认再继续。

- 阶段 1：1 种风格、横框和竖框各 1 种正文版式：导入照片（读取宽高）→ 按方向自动填入（填满裁切）→ 渲染 → 保存单页图片到相册，真机跑通
- 阶段 2：书籍信息填写和随时修改 + 封面、扉页、封底；版式 × 风格数据结构
- 阶段 3：照片选择面板（页码标签、筛选、高亮）+ 照片拖动缩放调整 + 填满/完整切换 + 跨页增删排序 + 双页预览
- 阶段 4：PDF 导出（分享版、打印版、发送到聊天、打开预览、进度显示）+ 图片导出（选页、跨页）
- 阶段 5：全部正文版式 + 3 种风格（胶片、手账、极简）+ 按跨页混搭 + 首页按风格/主题筛选
- 阶段 6：退出提示；补到 10 种风格；写 README（项目结构、如何新增风格和版式）
