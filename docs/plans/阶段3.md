# 阶段 3 方案：照片面板 + 拖动缩放 + 跨页管理 + 双页预览

> 确认日期：2026-10-17。三个决定点按推荐：点有照片的框先选中再出操作栏；换版式在本阶段做；首页「继续编辑 / 重新排版」。

## 分两步交付
- **3a**：照片选择面板、拖动缩放、填满 / 完整切换、首页照片拖动排序（含缩略图 thumbPath、继续编辑 / 重新排版）。完成后停下来真机测试并提交。
- **3b**：跨页管理（增删、排序、换版式）、双页预览（含 renderSpread、跨页缩略图）。

## 目标
1. 照片选择面板：页码标签、「全部 / 未使用」筛选、当前照片高亮
2. 照片在框内调整：单指拖动、双指缩放、填满 / 完整切换
3. 跨页增删、排序（只针对正文跨页；封面、扉页、封底位置固定）
4. 双页预览：封面单独在右，正文两两成对，封底单独在左，左右滑动翻页
5. 首页照片拖动排序（阶段 1 推迟过来的）

## 1. 编辑页交互
```
┌───────────────┐
│   当前页画布   │  点照片框 → 选中（画布上画高亮描边，不进入导出）
└───────────────┘
 ‹  P3  5/12  ›         参考线
 普通状态：[书籍信息] [管理跨页] [预览] [保存本页]
 选中照片框：[换照片] [调整] [填满 ⇄ 完整] [完成]
 调整模式：「单指拖动 · 双指缩放」 [复位] [完成]
```
- 点空照片框：直接打开照片面板。
- 点已有照片的框：选中，底部换成照片框操作栏。
- 点框外：取消选中。左右滑动：翻页（调整模式下不翻页，手势交给照片）。
- 碰撞检测考虑照片框旋转（为后续带旋转的版式准备）。

### 拖动 / 缩放
- 拖动：手指位移换算成 `offsetX / offsetY` 的变化（-1 ~ 1，按当前可移动范围换算），超出范围就停在边上。
- 缩放：`scale = 起始 scale × 两指距离比`，范围 1 ~ 4，1 即刚好填满。
- 重绘用 `canvas.requestAnimationFrame` 节流，每帧最多画一次。
- 「完整」模式下照片完整居中，不能拖动和缩放（「调整」按钮置灰）；切回「填满」后恢复之前的偏移和缩放。
- 「复位」：偏移归 0，缩放归 1。

## 2. 照片选择面板（组件 `components/photo-picker`）
- 底部弹出，占屏幕约 70% 高度，3 列网格。
- 顶部「全部 / 未使用」切换，显示数量。
- 右上角标签：显示这张照片所在的页，如「P3」「P3 P8」；用在封面显示「封面」；超过 3 个时显示「P3 P8 P12 +2」。
- 已使用的不变灰；当前框里的照片加高亮边框。
- 点照片：替换当前框，偏移 / 缩放 / 模式重置为默认，关闭面板，重绘。
- 用量由 `core/usage.js` 的 `getPhotoUsage(album)` 根据 `getPageList()` 的 `label` 统计。

## 3. 缩略图
- 导入时额外生成 `thumbPath`（长边 360，`wx.compressImage`），首页网格和照片面板都用它，减少大量 2048 图同时解码的内存占用。
- 跨页缩略图和预览图：`core/render/thumbnails.js` 用一个离屏 canvas 逐个渲染成图片文件，按内容（版式、风格、照片框、书籍信息）生成缓存 key，内容没变就复用。

## 4. 跨页管理页 `pages/spreads`
- 列表显示每个跨页的缩略图和页名（封面 / 扉页 / P1–P2 …）。
- 封面、扉页、封底固定在首尾，不能删除和移动。
- 正文跨页：长按拖动排序；「⋯」菜单：在后面插入跨页 / 换版式 / 删除（删除要确认）。
- 底部「添加跨页」：选版式后追加到正文末尾，照片框为空，回编辑页点框选照片。
- 点某个跨页：回到编辑页并跳到该跨页的左页（用 navigateTo 的 eventChannel 传回）。
- 换版式：保留原照片的先后顺序，依次放进新版式的照片框；新版式框更少时，多出的照片从这个跨页移除（仍在照片库中，面板里显示为未使用），并 toast 提示「有 N 张照片移出本跨页，可在照片面板的“未使用”中找到」。

## 5. 双页预览 `pages/preview`
- swiper 左右滑动，每屏一个跨页（3:2），下方显示页名。
- 封面：左半边留空，封面在右；封底：封底在左，右半边留空。
- 只渲染当前和前后各 1 个跨页，其余用到时再渲染。
- 从编辑页进入时，打开到当前跨页。

## 6. 渲染调整
- `renderPage` 不再重置画布变换，调用方可以先平移再画（跨页图 = 左页 + 右页画到同一张画布）。
- 新增 `core/render/renderSpread.js`：把一个跨页画成一张 3:2 图，缩略图、预览、阶段 4 的跨页图片导出共用。
- `renderPage` 的 `options.selectedFrameId`：画选中高亮描边（只在编辑页使用）。

## 7. 首页
- 照片网格长按拖动排序（`core/ui/sortable.js`，跨页管理页共用）。拖动期间禁止页面滚动。
- 已经生成过书时，底部按钮变成「继续编辑」和「重新排版」：
  - 继续编辑：保留所有编辑，新加的照片在面板中显示为未使用。
  - 重新排版：确认后按当前照片顺序重新生成整本书（会覆盖编辑）。
- 首页删除照片后点「继续编辑」：用到这张照片的照片框变为空框（显示占位色），不能报错或显示破图。

## 验证
- 面板：标签与实际页码一致；同一照片用在多页显示多个标签；封面显示「封面」；筛选数量正确；高亮正确。
- 调整：拖到边缘停住；缩放最小刚好填满；切到完整再切回保持原位置；换照片后重置；保存到相册与画面一致。
- 跨页：插入、删除、拖动排序、换版式后，编辑页页名和照片面板标签同步更新。
- 预览：封面在右、封底在左、正文成对，滑动流畅；改动后预览图更新。
- 首页：拖动排序后重新排版，顺序正确；继续编辑不丢失修改；删除正在使用的照片后继续编辑，对应框为空框、无报错。
- 换版式移出照片时出现 toast，被移出的照片在面板「未使用」中。
