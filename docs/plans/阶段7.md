### 黑白先做真机验证
按阶段 5 记下的要求：验证页新增两项，先在真机上确认哪种黑白方式可用，再定黑白风格的实现：
- ① `ctx.filter = 'grayscale(1)'`
- ② 照片裁切区域内用 `globalCompositeOperation = 'saturation'` 叠灰色
都不可用时：不做逐像素处理，黑白风格改为「高对比 + 照片叠深色 multiply」的近似效果，并告诉你。

### 滤镜验证结论（2026-10-17，iPhone 16 Pro Max / iOS 18.7.7 / 微信 8.0.79 / 基础库 3.17.4）
| 方式 | 页面画布 | 离屏画布 |
|---|---|---|
| ① `ctx.filter = 'grayscale(1)'` | ❌ 没有 filter 属性 | ❌ |
| ② 照片区域内 `saturation` 叠灰 | ✅ rgb(162,162,162) | ✅ |
| `screen` 滤色提亮 | ✅ | ✅ |
| `multiply` 正片叠底 | ✅ | ✅ |
- 黑白风格用方式②；港风暖调用 multiply，日系提亮用 screen。安卓未测试。

## 立体翻书展示（预览页）
- 预览页改成书本：左右两页并排，翻页时右页沿书脊翻起（CSS 3D：`perspective` + `rotateY` + `backface-visibility`），正面是当前右页，背面是下一跨页的左页。
- 手指拖动时页面跟手翻（WXS 直接改 transform，流畅），松手过半完成翻页、不过半弹回；点左右边缘也能翻。
- 封面单独在右、封底单独在左（沿用现有规则）；页图沿用跨页图片渲染器，按需生成。

## 退出提示（方案 B）
- 每次打开小程序后，第一次进入编辑页时轻提示一次：「相册只保存在本次使用中，关闭小程序后不会保留，记得导出 PDF」。
- 导出页常驻一行同样意思的小字。
- 不在编辑页返回时拦截（返回首页不会丢失相册）。

### 背景
需求原文：「用户在编辑页点返回时，用 wx.enableAlertBeforeUnload 提示『退出后当前相册不会保存』」。
实际情况：从编辑页返回首页**不会丢失**相册（相册在内存中，回首页还能「继续编辑」）；真正丢失是**关闭小程序**时，而关闭小程序（右上角胶囊）无法拦截。所以按原文实现，提示内容会与实际不符。建议见下方确认点。

## 7a 实现记录（2026-10-17）
- **引擎**：`core/render/paperCraft.js`
  - `photoFilter`：`grayscale`（saturation 叠灰）、`tint`（multiply / screen 叠色）、`lightLeak`（照片一角 screen 径向渐变），只作用于照片区域
  - `photoFrame.ticketStub` 票根副券（照片区域让出一条，撕线 + 缺口 + ADMIT ONE + 照片编号；横框在右、竖框在下）
  - `photoFrame.backing` 撕边垫纸（画在照片下面）
  - 照片框装饰 `outline` 霓虹描边；`layer: 'frame'` 的装饰跟着自己那张照片画（叠压时被前面的照片盖住）
  - 邮戳可单独使用（无邮票时压在照片角上，`position: 'top-left'`）
  - 装饰 `halftone` 半调网点色块
  - 代码纹理 +2：`kraft` 牛皮纸、`newsprint` 报纸
- **阅读顺序**：页内照片框统一按「从上到下、从左到右」排列（`registry.readingOrder`），照片填充和照片编号都按视觉顺序（修正右页镜像后左右颠倒的问题）。
- **风格组 +6**：独立 Zine `zine`、票根邮戳 `ticket`、拼贴剪报 `collage`、复古港风 `hkretro`、日系清新 `japanese`、黑白 `mono`（含反色跨页）。共 18 个风格。
