# 编辑页改版方案

> 范围：第一到第六部分（翻页、底部工具栏、顶部栏、拆分「管理跨页」、模板面板、界面用词）。第七部分「页面缩略图条」等确认后再做。
> 配色沿用暗房灰卡（`app.wxss` 的 CSS 变量），照片书模板本身的配色不动。
> 会新建文件 → 测试前需要重启开发者工具、清缓存、重新生成预览二维码。

---

## 0. 已确认（2026-10-18）

4 点都同意，另有补充：
- 「P3–P4」模式下，主模板对应的那张缩略图加一个小标注「整本书」，说明选它就是恢复跟随整本书。
- 选中照片框时，「完成」的图标和文字用靛蓝 `#2C3E66`，比另外三项醒目，但不是实心按钮。
- 图标统一放在 `assets/icons/`，README 里写明图标用到的颜色值。

## 0.1 原待确认的点

1. **怎么「恢复跟随整本书」**：模板面板的「P3–P4」模式下，如果这一对页面单独换过风格，面板顶部显示一行小字链接「恢复跟随整本书（当前：杂志）」。另外，在「P3–P4」模式下点选的风格如果正好就是整本书的主模板，也视为恢复跟随，以后换主模板时它会跟着变。原来模板页里的「跟随主模板」卡片不再需要。
2. **「整本书」模式的缩略图**：每个风格一行，左边是封面，右边是第一个正文页面，两张 3:2 缩略图并排。「P3–P4」模式每行两个风格，一张缩略图。
3. **选中照片框时的工具栏**：底部标签栏原位换成照片操作（换照片、调整、填满 / 完整、完成），同样是图标在上、文字在下，没有实心按钮，保证「导出」是唯一的实心按钮。
4. **图标的实现**：放在包里的 SVG 文件（`assets/icons/`），用 `<image>` 显示。SVG 文件读不到 CSS 变量，所以图标颜色写在文件里（主文字色 `#1E1F22`，参考线开启状态另有一个白色版本），禁用和未激活状态用透明度表示。这是「不写死颜色」的唯一例外。

## 1. 编辑页布局（从上到下）

```
┌──────────────────────────────┐
│ 微信导航栏（不改）            │
├──────────────────────────────┤
│ ▦ 参考线               [导出] │  顶部栏，约 36px
├──────────────────────────────┤
│                              │
│           画  布              │  占满剩余高度
│                              │
├──────────────────────────────┤
│        ‹     P3     ›        │  翻页行，约 40px
├──────────────────────────────┤
│  📖      ▤      ◐      👁    │  底部标签栏，约 56px + 安全区
│ 书籍信息  页面   模板   预览   │
└──────────────────────────────┘
```

- **画布尺寸**：改为在页面布局完成后量出画布区域的实际高度再计算，不再用写死的 `TOOLBAR_HEIGHT = 170`。新的上下栏合计约 132px + 安全区，比现在的 170px 还少，画布不会变小。

## 2. 翻页（第一部分）

- **箭头**：「上一页」「下一页」改成无边框的细线左右箭头图标，点击热区约 44px。第一页和最后一页时箭头变淡（透明度 0.3）。
- **页名**：两个箭头中间是纯文字的页名，比如「封面」「扉页」「P3」「P3–P4」（双页大图的那一页）。字号 30rpx，主文字色，没有底色和边框。原来的黄底页码标签去掉。
- **滑动翻页**：现有代码已经支持。普通状态和选中照片框状态下左右滑动超过 50px 就翻页，翻页时取消选中；调整照片模式下手势交给照片，不翻页。这部分保持不变，只做测试确认。

## 3. 底部标签栏（第二部分）

- **样式**：四项均匀分布，图标在上、文字在下，没有边框和底色。图标 44rpx，文字 22rpx 次要文字色。
  - 书籍信息：打开书籍信息页，和现在一样。
  - 页面：打开页面管理页，也就是原来的「管理跨页」，见第 5 节。
  - 模板：从底部弹出模板面板，见第 6 节。
  - 预览：打开翻书预览，和现在一样。
- **图标**：细线风格，24×24 viewBox，线宽 1.6，圆角端点，统一尺寸。
  - 书籍信息：一本合起来的书。
  - 页面：两张叠放的纸。
  - 模板：调色板。
  - 预览：一本翻开的书。
- **选中照片框时**：同一位置换成「换照片 / 调整 / 填满或完整 / 完成」四项，同样的图标加文字样式。不可用的项变淡。
- **调整照片时**：换成「单指拖动 · 双指缩放」提示文字和「复位 / 完成」两项。

## 4. 顶部栏（第三部分）

- 位置在微信导航栏下方、画布上方，高度约 72rpx（36px）。不使用自定义导航栏。
- **左侧**：参考线小图标开关，默认关闭。
  - 关闭：细线图标，次要文字色。
  - 开启：图标放在 6rpx 圆角的靛蓝小方块上，图标变白。
- **右侧**：「导出」按钮，靛蓝 `#2C3E66` 实心白字，高约 56rpx，6rpx 圆角。它是整个编辑页唯一的实心按钮。
- 「相册不会保存」的提示条仍然浮在顶部，不占布局。

## 5. 「页面」（第四部分：拆分管理跨页）

- 沿用 `pages/spreads` 页面，导航栏标题改为「页面」。
- **去掉**：
  - 顶部「主模板：xx 更换 ›」一栏。
  - 「⋯」菜单里的「换风格」。
- **保留**：长按拖动排序、插入、换版式、删除、点击回到编辑页并跳到那一页。
- **菜单和按钮改名**：
  - 「⋯」菜单：「在后面插入页面 / 换版式 / 删除这一对页面」。
  - 底部按钮：「添加页面」。
- **列表副标题**：单独换过风格的那一对页面，副标题仍然显示风格名，比如「横图 · 2 张 · 杂志」，方便知道哪些页面单独换过。

## 6. 「模板」面板（第五部分）

- **新组件** `components/style-sheet`：从底部弹出，高 80vh，不跳转页面。
- **顶部两个选项**（分段切换，选中项用靛蓝底白字）：
  - 「P3–P4」：只换当前页所在的这一对页面。封面、扉页、封底显示中文名。
  - 「整本书」：换主模板。单独换过风格的页面保持不变。
- **内容**：按「纯色 / 风格 / 主题」分组，每组一个小标题。纯色也用缩略图，不再用小圆点。
  - 「P3–P4」：每行两个风格，每个风格一张 3:2 缩略图，用真实照片渲染当前这一对页面套用这个风格的效果，下面写风格名。
  - 「整本书」：每行一个风格，两张缩略图并排（封面、第一个正文页面），下面写风格名。
- **当前风格**：缩略图加 4rpx 柯达黄 `#F5B800` 边框，名字旁边有黄底「当前」小标签。
  - 「P3–P4」模式下，当前风格是这一对页面实际在用的风格（单独设的，或跟随整本书的）。
  - 「整本书」模式下，当前风格是主模板。
- **点选后**：立即应用并关闭面板，编辑页重绘，toast 提示「已应用到 P3–P4」或「已应用到整本书」。
- **渲染与缓存**：
  - 沿用 `createSpreadImageRenderer`：内容有缓存时直接用，串行渲染不会卡。
  - 渲染器由编辑页持有，面板关掉再打开，已渲染的缩略图还在；离开编辑页时释放。
  - 每张缩略图对应一个虚拟页面 id（`sty_<风格>_<页面>`），缓存键含版式、照片、书籍信息，内容变化后自动重画。
  - **按需渲染**：用 `IntersectionObserver` 只渲染滚到可视区附近的卡片。打开时先渲染当前风格所在的那一组，再往外扩。缩略图宽 360px，和页面管理的缩略图同档。
- **不变的地方**：首页的「模板」卡片和第一次「开始制作」时的模板选择页（`pages/templates`）保持现状，只改提示文字里的用词。原来的「给单个跨页换风格」模式（`mode=spread`）入口已经去掉，相关代码一并删除。

## 7. 界面用词（第六部分）

- **页名格式**：`album.js` 里双页大图的页名从「P3-4」改为「P3–P4」。这样编辑页、照片面板的页码标签、页面管理、导出页、预览全部统一。
- **把「跨页」改掉的地方**：
  | 位置 | 原文 | 改为 |
  |---|---|---|
  | 编辑页 | 管理跨页 | 页面（标签栏） |
  | 页面管理 | 添加跨页 / 在后面插入跨页 / 删除跨页 | 添加页面 / 在后面插入页面 / 删除这一对页面 |
  | 页面管理 | 点击跨页回到编辑 · 长按正文跨页拖动排序 | 点击回到编辑 · 长按正文页面拖动排序 |
  | 页面管理 | 还没有正文跨页，点下方「添加跨页」 | 还没有正文页面，点下方「添加页面」 |
  | 页面管理 | 有 N 张照片移出本跨页 | 有 N 张照片移出这两页 |
  | 版式面板 | 跨页大图（分组名） | 双页大图 |
  | 导出页 | 跨页 2160×1440 | 双页 2160×1440 |
  | 模板页 | 之后可在「管理跨页」中更换，也可以给单个跨页换风格 | 之后可在编辑页的「模板」中更换整本书或单独两页的风格 |
- 代码、注释和需求文档里的命名不改。

## 10. 实现记录（第一到第六部分）

- **编辑页布局**：画布尺寸在 `onReady` 量出 `#stage`（画布区）的实际尺寸后计算，量到之前按窗口高度减 136px 和底部安全区估算。
- **翻页**：左右滑动翻页沿用原有逻辑，没有改动。普通和选中状态下可滑，调整照片时不翻页。
- **图标**：共 14 个，放在 `assets/icons/`。其中 `guides-on.svg` 是白色，`check-brand.svg` 是靛蓝，其余都是主文字色。颜色值写进了 README 的「界面配色」一节。
- **模板面板** `components/style-sheet`：
  - 编辑页通过 `selectComponent('#styleSheet').open({ album, spread, label, renderer })` 直接传入相册引用，不经过 setData 序列化。点选后触发 `apply` 事件，由编辑页修改数据、重绘并弹 toast。
  - 「P3–P4」模式下选中主模板，等于恢复跟随整本书（`styleId = null`）。顶部的「恢复跟随整本书」链接效果相同。
  - 「整本书」模式下，封面或第一个正文页面如果单独换过风格，缩略图里保持它自己的风格，也就是换主模板后它真实的样子。
  - 缩略图渲染器宽 360px，用照片缩略图（thumb），由编辑页持有，离开编辑页时释放。打开面板时先滚动到当前风格，再用 `IntersectionObserver`（相对滚动区，上下各预留 360px）按需排队渲染。切换模式或关闭面板时清空队列。
  - 缩略图里不显示页码，因为虚拟跨页不在相册的页列表里，其他装饰和真实效果一致。
- **模板页**（`pages/templates`）：删除了 `mode=spread`，包括「跟随主模板」卡片。首页「模板」卡片和第一次「开始制作」的流程不变。
- **用词**：除第 7 节表格里的改动外，版式名「跨页大图 / 跨页满版」也改成了「双页大图 / 双页满版」，因为它们会显示在版式面板和页面列表里。
