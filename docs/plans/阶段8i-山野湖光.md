# 阶段 8i：山野湖光（山川湖泊主题，并入原「自然风光」）

> 2026-10-20。素材原图在 `../MyZine素材/山野/`，提示词见 `阶段8-素材提示词.md` 第 5 节。

## 素材（`pkg-mountain` 约 1.8MB，接近 2MB 分包上限）
- 贴纸 18 个：山水（雪山、湖边码头和小船、松树、红枫、瀑布、苔藓石头）、露营徒步（帐篷、篝火、登山靴、背包、指南针、搪瓷杯）、林间生灵（小鹿、松鼠、翠鸟、野花束、蘑菇、蓝蝴蝶）
- 纸材：绿格纹、叶子、牛皮纸纸胶带；浅绿方格便签、树叶便签；墨绿燕尾夹。背景是淡绿米白水彩纸纹。
- 码头的一小片水面伸进了松树那一格，切图时被并进了松树贴纸。为此给脚本加了 `dropSmall`：丢弃面积小于本格最大区域 5% 的碎片，只对这张图开启。

## 合并
- 删除 `templates/styles/nature.js`，`registry` 加别名 `nature → mountain`，旧相册自动显示为山野湖光。模板总数不变（自然风光换成了山野湖光）。
- 沿用自然风光：山峦 / 树林 / 丘陵剪影、拱形照片偏好、细线页眉、Playfair 衬线标题、装饰词池、国家公园式护照章、方印、山 / 枝叶 / 太阳 / 云朵线稿。
- 复用其他模板：邮票 + 邮戳（大海沙滩）；虚线路线（公路旅行，暖阳橙，当作徒步路线）。封面问候语是「Wandering in {location}」，没有地点时写「Into the Wild」。
