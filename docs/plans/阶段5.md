# 阶段 5 方案：全部正文版式 + 3 种风格 + 按跨页混搭 + 模板筛选

> 确认日期：2026-10-17。4 个决定点按推荐：分 5a / 5b；素材以代码绘制为主，手账纸张纹理由程序生成并放入分包；本阶段不加载自定义字体；模板入口为首页卡片 + 模板页。

## 目标
1. 正文版式补全：单张大图、双图、三图、四图、图 + 留白、跨页大图；同一张数有横框和竖框的组合
2. 3 种风格：胶片、手账、极简（已有）
3. 按跨页混搭风格
4. 选择主模板，可按风格 / 按主题筛选
5. 「新增风格只加数据和素材，不改代码」：渲染引擎补齐通用能力

## 建议分两步
- **5a 版式**：页面组件 + 约 14 个正文版式、自动排版加权轮换、编辑页支持跨页大图（3:2 画布、始终显示中缝线）。
- **5b 风格**：渲染引擎扩展（纹理背景、颗粒、装饰、照片框装饰、风格旋转）、胶片和手账风格、素材分包机制、模板选择页（风格 / 主题筛选）、按跨页换风格。

## 1. 正文版式（5a）
### 页面组件（单页坐标，左页外侧留白大、内侧小，右页自动镜像）
| 组件 | 内容 |
|---|---|
| L1 | 一张横图（3:2），垂直居中 |
| P1 | 一张竖图（3:4） |
| L2 | 两张横图上下排列 |
| P2 | 两张竖图左右并排 |
| M3 | 上一张横图 + 下两张竖图 |
| G4 | 2×2 四宫格 |
| W1L / W1P | 一张较小的横图 / 竖图 + 大面积留白 |

`templates/layouts/parts.js` 定义组件，`mirror()` 生成右页版本；版式文件只写组合，减少重复坐标。

### 跨页版式（约 14 个）
| 版式 | 左页 + 右页 | 张数 |
|---|---|---|
| 横·左右各一 | L1 + L1 | 2 |
| 竖·左右各一 | P1 + P1 | 2 |
| 横竖混排 | L1 + P1、P1 + L1 | 2 |
| 横·每页两张 | L2 + L2 | 4 |
| 竖·每页两张 | P2 + P2 | 4 |
| 一竖两横 | P1 + L2、L2 + P1 | 3 |
| 三图页 | M3 + L1 | 4 |
| 四宫格 | G4 + P1 | 5 |
| 留白 | W1L + L1、W1P + P2 | 2 / 3 |
| 跨页大图 | 一张横图横跨两页（span: spread） | 1 |

### 自动排版
- 沿用「方向匹配分 → 同分轮换」。版式变多后，完全匹配的版式会有很多个，按「已使用次数 / 权重」轮换，避免单调。
- 版式新增 `autoWeight`：普通 1；留白 0.5；跨页大图 0.3（偶尔出现）；0 表示不参与自动排版（仍可手动选择）。
- 跨页大图不连续使用。

### 编辑页支持跨页大图
- 当前页是跨页大图时画布变为 3:2，翻页时自动调整画布尺寸并重新测量位置。
- 跨页大图始终显示中缝参考线（需求要求），参考线开关只控制安全边距。

### 5a 真机反馈后的调整（2026-10-17）
- 问题：「换版式 / 添加跨页 / 插入跨页」无反应。原因是 `wx.showActionSheet` 最多 6 项，版式超过后调用失败。改为版式选择面板 `components/layout-picker`：按张数分组，显示每个版式的示意图，当前版式高亮。
- 反馈：排版单调（几乎都是居中的单张大图）。重新设计页面组件，共 25 个正文版式，总览见 `阶段5a-版式总览.png`。设计原则：
  - 不总是居中：贴上沿、贴下沿、贴外侧、靠内侧等不同锚点
  - 大小对比：一大一小、满版 + 小图、四宫格 + 小图（密与疏）
  - 错落：两页照片一高一低，对齐到共同的上沿 / 下沿
  - 留白：小图 + 大面积空白
  - 版心：外侧 96、内侧 72、上 96、下 120（下边距略大，书籍常用比例），照片间距 40
- 满版（F、跨页满版）：照片铺到页面边缘（出血），单页满版内侧仍保留 72，不进入中缝。当前不支持印刷出血（3mm），冲印裁切时边缘可能有细白边。
- 自动排版：选某版式会导致最后只剩 1 张照片时降低优先级（剩 1 张只能进跨页大图的横框）。
- 满版保持出血效果（用户确认）。
- 页码：正文页外侧下角（左页左下、右页右下，与外侧照片边缘对齐，距下边 60），由风格的 `pageNumber` 控制；被照片盖住时（满版）不画。封面、扉页、封底不编页码。
- 节奏：4 张及以上算「密」，密的跨页之后优先选疏的（同分时的第一判断条件）。

## 2. 风格（5b）
### 渲染引擎补齐的通用能力（新增风格只写数据）
| 能力 | 数据写法 |
|---|---|
| 纹理背景 | `background: { type: 'image', src, repeat: 'tile' \| 'cover' }` |
| 颗粒感 | `grain: { opacity }`，代码生成噪点图后平铺 |
| 页面装饰 | `decorations`：rect、line、text（固定文字）、image、perforation（胶片齿孔） |
| 照片边框 | `photoFrame`：边框宽度 / 颜色、底边加宽（拍立得效果）、阴影 |
| 照片框装饰 | `frameDecorations`：tape（和纸胶带，代码绘制）、dateStamp（橙色日期戳，取旅行开始日期，无日期时不显示） |
| 风格旋转 | `photoFrame.rotateJitter`：每个照片框按 id 稳定地随机旋转 ±N°（点击检测同步考虑） |

### 两种新风格
| 风格 | 效果 | 适合主题 |
|---|---|---|
| 胶片 | 深色底、页面上下胶片齿孔、照片细白边、橙色日期戳、颗粒感、浅色文字 | 城市夜景、公路旅行、人文建筑、情侣纪念、聚会 |
| 手账 | 米色纸张纹理、照片宽白边（拍立得）、轻微随机倾斜、和纸胶带、暖色点缀 | 美食、亲子家庭、萌宠、动物园或农场、游乐园、聚会 |
| 极简（已有） | 纯色、无装饰 | 自然风光、人文建筑、海边海岛、城市夜景 |

### 素材与分包
- 能用代码画的全部用代码画（齿孔、胶带、颗粒、边框、阴影）。
- 手账的纸张纹理是图片：放在分包 `styles-pkg/journal/`，渲染前 `wx.loadSubpackage` 加载。这套机制也给阶段 6 其余风格使用。
- 风格数据中 `assetsPackage` 标记分包名；渲染前统一由 `core/styleAssets.js` 加载分包和图片。

### 字体
- 中文手写 / 艺术字体单个文件通常数 MB，超过分包 2MB 上限，且用户文字无法预先裁剪字库，因此本阶段**不加载自定义字体**，各风格用系统字体（衬线 / 无衬线 / 等宽）区分。
- 以后如需特殊字体：只考虑用于日期、英文等固定内容的小型西文字体，且必须是 SIL OFL 等允许商用嵌入的授权。

### 主题
`templates/themes.js`：12 个主题（自然风光、人文建筑、美食、聚会、海边海岛、城市夜景、公路旅行、亲子家庭、情侣纪念、萌宠、动物园或农场、游乐园），风格的 `tags` 引用其 key。

## 3. 模板选择页 `pages/templates`（5b）
- **第一次点「开始制作」时先进入模板页**：可以选一个风格，也可以点「跳过」使用默认的极简；选完或跳过后再自动排版、进入编辑页。
- 之后从首页「模板」卡片（在书籍信息卡片下方，显示当前主模板）和跨页管理页随时更换。
- 顶部切换「全部风格 / 按主题」；按主题时显示 12 个主题标签，点选后筛出适合的风格。
- 每个风格卡片显示**用用户自己的照片渲染的示例跨页**（没有照片时用占位），以及风格名和适合的主题。
- 选中即设为主模板（`album.defaultStyleId`）；没有单独换过风格的跨页立即跟着变。
- 跨页管理页顶部显示「主模板：XX [更换]」，也可进入模板页。

## 4. 按跨页混搭（5b）
- 跨页管理「⋯」菜单新增「换风格」：列出全部风格，以及「跟随主模板」。
- 换风格以跨页为单位，左右两页一致（数据本来就在跨页上）。
- 列表中单独换过风格的跨页显示风格名。

## 记给阶段 6
- 黑白风格先试两种方式，真机验证可用就不做逐像素处理：
  1. `ctx.filter = 'grayscale(1)'`
  2. 在照片框裁剪范围内，用 `globalCompositeOperation = 'saturation'` 叠一层灰色
