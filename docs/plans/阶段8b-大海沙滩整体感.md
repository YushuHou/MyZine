# 阶段 8b 方案：大海沙滩 × 海边明信片融合，加强整体感

> 2026-10-20。用户反馈（8a 预览之后）：
> ① 和「海边明信片」融合，元素更多、搭配更丰富；
> ② 照片占比小的跨页，装饰可以多一些；
> ③ 整体感不够，像零散的素材贴在书上。参考：济州岛蓝色手账（跨页大色块、照片和手写标题成组、颜色统一）、「Drift」「晚风过湖」（撕纸层横贯画面）。

## 1. 融合海边明信片

- 「海边明信片」并入「大海沙滩」，模板列表里只保留大海沙滩（共 23 套）。旧相册里引用 `postcard` 的跨页自动显示为大海沙滩（`registry` 别名）。
- 并入的元素：
  - **邮票 + 邮戳**：邮票框里画**水彩贴纸**（不再是线稿），邮戳圆环写地点和日期。
  - **航空信封红蓝斜条**：封面一定有；正文作为一种大装饰偶尔出现。
  - **护照章、行李吊牌**：作为小装饰，权重低。
  - **封面问候语**：「Greetings from {location}」。
  - **少量细线稿**（波浪线、太阳、闪光）：只在装饰多的跨页里点缀。
- 本页最大照片上的「点睛装饰」每跨页**二选一**：邮票 + 邮戳，或照片角贴纸。

## 2. 照片少，装饰多

- 计算跨页的**照片覆盖率**（照片框面积 ÷ 页面面积，左右页取平均）。
- 风格配置 `smallByCoverage` 按覆盖率决定小装饰数量。大海沙滩：覆盖率 < 35% 放 5–6 个，35%–55% 放 3–4 个，> 55% 放 2–3 个。
- 左右页按留白多少分配：留白多的那页多放。

## 3. 整体感

1. **跨中缝的撕纸色带**（新大装饰 `paperBand`）：一条横贯左右两页的撕边纸带，衬在照片下面。两条长边是撕口，带白色纸芯和投影。毛边按整个跨页的坐标生成，过中缝时连续。颜色取本跨页的主色调。
2. **跨页主色调**：每个跨页选一个主色（雾蓝 / 海水青 / 珊瑚橘），晕染、色带都用它。左右页晕染同色（现在是各自随机）。
3. **贴纸分主题**：贴纸分成三组：海边生物（海鸥、贝壳、海星、海螺、浪花）、沙滩一日（遮阳伞、救生圈、草帽、人字拖、沙桶、冰淇淋、冲浪板）、港口（帆船、木船、灯塔、椰子树）。每个跨页先从一组里挑，不够再从别组补，同一个跨页讲一个小故事。
4. **贴纸围着照片成组**：贴纸优先放在照片的角和边上，压住照片一小角，形成「照片 + 胶带 + 贴纸」的组合；放不下再放留白处。

## 4. 验证

- 离线预览：照片少的、多的、跨中缝的各种跨页，加上封面。
- 旧模板渲染不变。

## 实现记录（2026-10-20）

- **融合**：删除 `templates/styles/postcard.js`，`registry` 加别名 `postcard → beach`，模板共 23 套。`core/render/postcard.js`（邮票、邮戳、斜条的绘制）保留。
- **点睛装饰**：风格 `frameAccents` + 照片框装饰的 `accent` 键。大海沙滩：邮票邮戳 1，照片角贴纸 1.6。
- **大装饰**：可以同时有多个（`bigPerSpread`，大海沙滩为 1–2 个）。新增 `paperBand`（`core/render/paperBand.js`）。色带的高度在 y 范围内取 9 个候选，选被照片挡住比例最接近 35% 的那个，让色带半压在照片下，不至于全被盖住；色带上叠一层纸纹（正片叠底）。
- **主色调**：`ornaments.tones`，晕染和色带共用，左右页一致。
- **贴纸**：`stickerGroups` 按主题优先挑；`anchorChance`（0.6）的贴纸先找照片角装饰位（压住照片一小角，整页满版照片不贴）；照片角贴纸和邮票占的位置，小装饰会避开。
- **数量**：`smallByCoverage`，左右页按留白比例分配。
- 离线预览确认：色带在跨中缝时连续；其余模板的绘制逻辑没有改动（示例跨页 id 带时间戳，所以每次预览的随机装饰会不同）。
