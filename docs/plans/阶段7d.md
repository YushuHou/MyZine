## 0. 需要你确认的点

1. **大号数字显示什么**：建议默认显示**正文跨页序号**（01、02、03…，像杂志的章节号）。另外两个可选：
   - 页码。页面下角已经有页码了，再来一个大号的会重复。
   - 「DAY 1」这样的第几天。现在照片没有按日期分组，跨页和日期对不上，所以暂不建议。
2. **撕纸条上写什么**：建议在两种内容里轮换：
   - 短句：每个风格新增 `stripPool`，20 条左右，整本书不重复，比如 `best day ever`、`remember this`、`no filter`。
   - 地点和日期：`{location} · {date}`，只在这两项都已填写时才出现。
   不和大标题的装饰词共用词池，避免同一跨页出现两个一样的英文。
3. **分配方案**：见第 4 节，你可以直接改。

## 1. 撕纸条（新文件 `core/render/paperBits.js`）

### 样子
- **形状**：一条窄长纸条，长 260–420、高 64–90 基准 px。两条长边是撕开的毛边，两端可以剪直或也撕开。
- **毛边**：沿撕开的边走带随机起伏的折线，内侧再加一条 3–5 px 的浅色纤维边，看起来像纸被撕开后露出的白芯。
- **纸材**（风格可选）：
  - 白纸
  - 横线本子纸（复用 7c 的 `lined` 纹样）
  - 牛皮纸（复用现有牛皮纸纹理的底色）
  - 旧报纸色
  - 风格中的任意颜色
- **文字**：用字形字体。手账类风格用 Caveat 手写体，拼贴 / zine 用 Oswald 打字机感，中文回退系统字体。太长时自动缩小字号。
- **其他**：轻微旋转 ±6°，有柔和投影，和胶带同一套阴影参数。

### 两种用法
1. **压在照片边上**（照片框装饰，`frameDecorations: [{ type: 'tornStrip', … }]`）
   - 只贴在本页最大的照片上，斜压在照片左下或右下角，约一半露在照片外面，像照片上贴了一张标签。
   - 和胶带一样，最后画，可以压住相邻照片。
   - 每个跨页最多 1 条。
2. **放在留白处**（小装饰，`ornaments.small: [{ type: 'tornStrip' }]`）
   - 和线稿、印章一样摆在候选装饰位，避开照片和文字。

### 配置
```js
{ type: 'tornStrip', paper: 'lined' | 'white' | 'kraft' | 'news' | '<颜色>', size: [260, 380], height: 72,
  font: { glyph: 'caveat', size: 40, color: 'text' }, text: ['pool', 'place'], tornEnds: true }
```

## 2. 行李吊牌（同一文件 `paperBits.js`）

### 样子
- **外形**：竖长卡片，约 170 × 300 基准 px。上端两角切成斜角，靠上居中打一个孔，孔周围有一圈加固垫圈（深色描边圆环）。
- **绳子**：从孔里穿出两股贝塞尔曲线，弯向页面外侧，在中途打一个小结，末端在页边被裁掉，像从页外垂进来。颜色是麻绳色，风格可改。
- **卡面**，从上到下：
  - 顶部色带，写 `BAGGAGE` 或 `TAG`，颜色取风格的强调色。
  - `TO` 一栏：写 `{location}`，下面有一条填写线。
  - `DATE` 一栏：写 `{date}`。
  - `FLIGHT` 一栏：写一个稳定生成的「航班号」，比如 `MZ 1018`，取日期的月日。
  - 底部一条随机粗细的条形码。
- **缺字段时**：对应的那一栏留空线，像没填的吊牌。地点和日期都为空时仍然画，只是空着。
- **其他**：旋转 ±15°，有投影，纸色可选白、牛皮纸、风格色。

### 规则
- 小装饰类型 `luggageTag`，每个跨页最多 1 个。
- 尺寸较大，摆放时用 7c 的逐级缩小策略：100% → 80% → 65%。
- 绳子允许伸到页边外（会被页面裁切掉），不算占位。

### 配置
```js
{ type: 'luggageTag', size: [260, 320]（卡片高，基准 px）, paper: 'kraft', band: 'accent', string: '#B89A6A', weight }
```

## 3. 大号描边数字（本阶段不做，保留设计）

### 样子
- 超大的两位数（如 `07`），字高为页高的 30%–45%，用字形字体的轮廓**描边、不填充**（空心字），线宽 3–5 基准 px。
- 两种效果可选：
  - **错位双线**：再画一层偏移 10–16 px 的描边，颜色更淡，像套印没对准。
  - **霓虹发光**：加 shadowBlur 发光，给港风用。
- 默认用 Oswald（窄、高，最有杂志感），也可以用 Playfair。

### 位置
- 属于大装饰（`ornaments.big: [{ type: 'bigNumber', … }]`），画在照片下面。
- 候选位置有 4 个：外侧上角、外侧下角、内侧下角、空白页的中部，挑和照片框重叠最少的一个。重叠不超过 35% 就可以用，因为数字在照片后面，被遮住一部分反而有层次。
- 自动避开文字槽：先画数字，再画文字，同时检查数字和标题槽不重叠，重叠就换位置。
- 左右页的跨页上只画在一侧，侧别随机。

### 实现要点
- `glyphText.js` 新增描边模式：沿用同一套字形路径，`ctx.stroke()` 代替 `ctx.fill()`。线宽要除以字形的缩放系数，保证粗细一致，做法和线稿一样。
- `album.js` 的 `getPageList` 给正文跨页加 `spreadNo`（第几个正文跨页，从 1 起）。

### 配置
```js
{ type: 'bigNumber', glyph: 'oswald', height: [0.3, 0.42], color: 'accent', lineWidth: 4,
  offset: { dx: 12, dy: 12, color: 'textMuted' } | null, glow: false, weight }
```

## 7. 实现记录

- **撕纸条**：`paperBits.js`。
  - 照片角用法（`frameDecorations.tornStrip`）由装饰计划选定一页，所以每跨页最多 1 条，`chance` 控制出现比例。
  - 留白处用法（`ornaments.small` 的 `tornStrip`）：风格已有照片角纸条时不再放。
  - 纸芯是比纸条大一圈、颜色更白的毛边层。横线纸复用 7c 的 `lined` 纹样。
- **短句分配**：`album.js` 把装饰词和短句的「整本书不重复」抽成同一个 `uniquePicker`。每个正文跨页分到一条 `strip`；约 35% 的跨页改写「地点 · 日期」（两项都已填写时）。
- **行李吊牌**：小装饰，每跨页最多 1 个。
  - 绳子伸向页面外侧，伸出页边的部分被页面裁切掉。
  - 航班号是 `MZ` 加开始日期的月日（如 `MZ 1012`），没有日期时用稳定的随机 4 位数。
  - 字段为空时只留填写线。
- **新增 ornaments 的风格**：Zine 和公路旅行原来没有 `ornaments`，这次新加了，只有小装饰，没有大装饰。原有的半调色块、路线仍按 decorations 出现。
- **短句词池**：手账、杂志拼贴、Zine 各 20 条，字形全部覆盖。
- **离线预览**：`阶段7d-前后对比.jpg`，6 个风格，每个风格改进前 / 改进后各 3 个跨页。
- **已知**：公路旅行的吊牌绳子偶尔会从副标题上方斜穿过去。吊牌本身避开了文字，绳子不参与避让。
