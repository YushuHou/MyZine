# 阶段 8f：心动旅程（情侣主题，不画人物）

> 2026-10-20。按用户要求，这套不画 Q 版人物，用情侣感的可爱元素。素材原图在 `../MyZine素材/情侣/`，提示词见 `阶段8-素材提示词.md` 第 2 节。

## 素材（`pkg-couple` 约 1.8MB，接近 2MB 分包上限，不要再往里加素材）
- 贴纸 18 个，分三组：
  - 浪漫物件：爱心气球、玫瑰花束、碰杯奶昔、对戒、礼物盒、情书
  - 约会小物：双球冰淇淋、热气球、摩天轮、拍立得、野餐篮、爱心蜡烛
  - 成对的小动物：兔子、小鸟、企鹅、小熊、天鹅、小猫
- 纸材：粉条纹、小爱心、粉色纸胶带；粉色方格便签、爱心便签；玫瑰金燕尾夹。背景是淡玫瑰粉水彩纸纹。

## 复用
- 大海沙滩：邮票（里面是浪漫小物）+ 邮戳。点睛装饰里邮票权重略高（1.2），呼应情书。封面问候语是「Love in {location}」，没有地点时写「Love Story」。
- 手账：撕纸条、爱心闪光星星线稿。

## 新增
- 飘雪支持 `shape: 'heart'`：飘落的小爱心。大的用主色、小的用淡色，略微倾斜。支持 `color` 指定颜色。
- 主色调：玫瑰粉为主，酒红和薄荷绿偶尔出现。薄荷绿色带和粉色互补，给整体加一点清爽。
