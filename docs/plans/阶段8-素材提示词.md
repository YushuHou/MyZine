# 阶段 8：其余 7 套模板的素材提示词

> 2026-10-20。用户要求一次给出后面所有模板的提示词，节省时间。
> 情侣、家庭两套按用户要求**不画 Q 版人物**，而是用适合情侣 / 家庭的可爱元素（成对的小动物、浪漫物件 / 动物一家、出游小物）。

## 通用规则（每套都一样）

1. 每套新开一个 ChatGPT 对话，**按顺序一次发一段**，满意了再发下一段。同一个对话里，后面几张会沿用前面的画风。
2. 每张出来检查：
   - 背景是不是均匀的浅灰色。
   - 物件有没有粘在一起，或者碰到画面边缘。
   - 有没有自己加白描边或文字。
   - 数量是不是 6 个。
   不合格就说「只改 XX，其他不变，重画」。
3. 同一个物件里的几样东西要连在一起（比如狗坐在车筐里），不能分成两块，否则会被切成两个贴纸。
4. 不要出现品牌标志、有版权的卡通角色、真实商标文字。画出来像的话重新生成。
5. 下载原图（不要截图），放进 `E:\work_project\MyZine素材\文件夹名\`。
