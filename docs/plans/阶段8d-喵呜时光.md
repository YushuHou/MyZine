# 阶段 8d：喵呜时光（猫咪主题）

> 2026-10-20。用户觉得「小猫猫」不适合当模板名，从「喵星来信 / 猫咪午后 / 毛茸茸日记 / 喵呜时光」中选了**喵呜时光**（id `cat`）。素材原图在 `../MyZine素材/猫咪/`。

## 素材（`pkg-cat` 约 1.4MB）
- 贴纸 18 个，分三组：
  - 猫咪姿态：睡觉的橘猫、伸懒腰的白猫、揣手的三花、露肚皮的蓝猫、纸箱里的奶牛猫、黑猫背影
  - 猫咪小物：毛线球、小鱼干、逗猫棒、猫碗、粉色爪印、铃铛项圈
  - 旅行中的小猫：行李箱上戴草帽的猫、帆布包里的猫、抱相机的猫、野餐篮旁的猫、纸飞机上的猫、抱信封的猫
- 纸材：粉格纹、爪印、奶油色纸胶带；粉色撕边便签、猫耳便签；粉色燕尾夹。背景是奶油粉水彩纸纹。

## 复用
- 大海沙滩：邮票（里面是小猫）+ 邮戳，和照片角贴纸二选一。封面问候语是「Meow from {location}」，没有地点时写「Meow Days」。
- 手账：点阵手账纸底纹（大装饰，权重低）、撕纸条（横线纸）、爱心 / 闪光 / 星星线稿。

## 新增
- `core/render/pawTrail.js`：猫爪印小路大装饰。一串爪印左右脚交替，从左页外侧走到右页外侧，按整个跨页的坐标生成，画在照片下面。
  - 粉色爪印印在粉色纸上看不清，所以用奶茶棕（`color: 'latte'`），尺寸 84、步距 150、透明度 0.5。
- 主色调：樱花粉为主，蜜桃橘、雾紫偶尔出现。
- 撕纸边比例比前两套低（0.3），保持软萌。
