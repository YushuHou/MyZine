# 阶段 2 方案：书籍信息 + 封面、扉页、封底

> 确认日期：2026-10-17

## 目标
书籍信息可以随时填写和修改；自动生成封面、扉页、封底，并显示对应信息；字段为空时自动收拢，不留空洞。

## 1. 书的结构
```
封面(单页，右) → [环衬 | 扉页] → 正文跨页… → 封底(单页，左)
```
- 扉页做成一个跨页：左页是环衬（风格的环衬色），右页是扉页。这样正文仍然两两成对，封底落在左侧，和预览规则一致。
- `core/book.js` 的 `buildBook(album)` 生成「封面 + 扉页 + 正文（autoLayout）+ 封底」，首页「开始制作」调用它。
- 封面放 1 张照片，默认用第 1 张（正文中也会出现，需求允许重复使用）。
- 阶段 3 的照片面板中，用在封面的照片标签显示「封面」而不是页码。`getPageList()` 为每页产出 `label`（封面 / 环衬 / 扉页 / P1… / 封底），标签直接使用它。

## 2. 书籍信息
- 新页面 `pages/info`：书名（20 字）、作者（20 字）、同游人（40 字）、旅行地点（20 字）、旅行日期、想说的话（200 字，多行），全部选填。
- 旅行日期：开始和结束两个日期选择器，结束日期可选（一日游只填开始）。数据存为 `dateStart` / `dateEnd`（`YYYY-MM-DD`）。显示格式：
  - 单日：`2026.10.01`
  - 同月：`2026.10.01 – 10.05`
  - 跨月：`2026.09.28 – 10.03`
  - 跨年：`2025.12.30 – 2026.01.02`
- 立即更新：输入时直接写入 `album.info`；编辑页 `onShow` 时重绘当前页。
- 入口：首页顶部「书籍信息」卡片（信息卡片在上，照片在下，不强制顺序）；编辑页工具栏「书籍信息」按钮。

## 3. 版式文字区 `layout.pages[].texts`
文字按「文字块」排版，空字段跳过、间距一起收掉：
```js
texts: [{
  id: 'cover-info', x: 0.0889, y: 0.9333, w: 0.8222,
  anchor: 'bottom',          // top 从 y 向下排 | bottom 从 y 向上排 | center 以 y 为中心
  align: 'left',             // left | center | right
  gap: 20,                   // 条目间距（基准 px）
  items: [
    { field: 'title', role: 'title', maxLines: 2, minScale: 0.7 },  // 先缩小字号，仍放不下再截断加省略号
    { field: 'locationDate', role: 'subtitle' },
    { field: 'author', role: 'caption' },
    { text: 'MADE WITH MYZINE', role: 'caption' },                   // 固定文字
    { field: 'companions', role: 'caption', prefix: '同游  ', gapBefore: 64 }  // gapBefore 覆盖该条目前的间距
  ]
}]
```
- `field` 由 `core/bookInfo.js` 取值；`locationDate` 为「地点 · 日期」，缺哪个去掉哪个，都空则隐藏。
- 版式页可加 `fill: 'endpaper'`，用风格中的该颜色铺满（环衬）。

## 4. 风格补充
```js
fonts: {
  title:    { family: 'serif', weight: 'bold',   size: 88, lineHeight: 1.25, color: 'text' },
  subtitle: { family: 'serif', weight: 'normal', size: 36, lineHeight: 1.4,  color: 'text' },
  body:     { family: 'serif', weight: 'normal', size: 34, lineHeight: 1.7,  color: 'text' },
  caption:  { family: 'sans-serif', weight: 'normal', size: 26, lineHeight: 1.5, color: 'textMuted', letterSpacing: 2 }
},
colors: { /* 原有 */ textMuted: '#8A847A', endpaper: '#E9E3D7' }
```
字号以 1080 宽为基准；`color` 是 `colors` 的键名。本阶段用系统字体，自定义字体放到阶段 5。

## 5. 新版式
| 版式 | 内容 |
|---|---|
| `cover.js` 封面（single） | 上方大照片框；下方文字块（底部对齐）：书名、地点 · 日期、作者 |
| `title.js` 扉页（pair） | 左页环衬；右页文字块居中：想说的话（多行，最多 10 行，先缩小到 70% 字号，仍放不下截断），然后作者 / 同游 / 地点 · 日期 |
| `back.js` 封底（single） | 底部居中：书名、MADE WITH MYZINE |

## 6. 渲染
- `core/render/text.js`：按字测宽换行（中文逐字，英文单词不拆）、最大行数、缩小字号、省略号、字间距、文字块堆叠。
- `renderPage`：背景 → 环衬底色 → 装饰 → 照片框 → 文字 → 参考线。页对象带 `info`。
- 单页（封面、封底）参考线只画安全边距。

## 验证
- 不填任何信息：封面只有照片，扉页右页空白，封底只有 MADE WITH MYZINE，无报错。
- 逐项填写，从编辑页进入修改后返回，封面 / 扉页 / 封底立即更新；清空某项后其余条目自动收拢。
- 日期四种格式；只填开始日期；结束早于开始时自动清除结束日期。
- 书名 20 字、想说的话 200 字：字号缩小，仍超出时截断加省略号，不超出安全边距。
- 保存封面到相册，与编辑页一致。
