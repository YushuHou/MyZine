## 1. 技术路线（沿用阶段 6 已验证的方案）

- 阶段 5b、6a 的真机验证结论：**画布读不到分包里的图片文件**，但分包里的 JS 模块可以用 `require.async` 加载；**画布可以加载 Data URL 图片**（iPhone 已验证）。
- 所以素材 = **PNG 转 base64，写进分包 JS 模块** → `require.async` 加载 → Data URL → `canvas.createImage()`。字形字体走的也是这条路。
- 每套模板一个分包：`pkg-beach/`（之后是 `pkg-snow/`、`pkg-cat/`……）。微信限制单个分包 ≤ 2MB，base64 比原文件大约 1/3，所以**每套素材的 PNG 总量控制在约 1.4MB 以内**。
- `require.async` 的路径必须是字面量，所以每个分包在加载表里写一行（和 `glyphText.js` 的 `LOADERS` 一样）。
- 格式先用 **PNG（脚本量化成 256 色调色板，保留透明）**，兼容性最稳。WebP 体积能再小一半，但 Data URL 的 WebP 在真机上还没验证过，等试点完成后再测。

### 素材分辨率
- 贴纸在页面上大约占 160–360 基准 px（单页宽 1080）。打印版每页宽 2480，是基准的 2.3 倍。
- 贴纸统一缩放到**长边 640px**：分享版足够清晰，打印版略软，但水彩风格本身边缘就柔和，可以接受。
- 背景纸纹：1024px 的无缝平铺图，存 JPG。

## 2. 素材处理脚本 `scripts/build-stickers.py`

输入一张 AI 生成的合集图，自动完成：
1. **抠背景**：从四角估算背景色（要求生图时用纯浅灰底），从画面边缘做泛洪填充，色差阈值以内的连通区域变透明，边缘羽化 1px，去掉灰边。
2. **切图**：按连通区域拆成单个物件，丢掉碎屑，四周留边后裁切。
3. **统一尺寸**：长边缩到 640px。
4. **加白色描边**（可选，按模板配置）：把透明通道扩张约 14px 填白，再在外面加一圈很淡的阴影。
5. **压缩**：量化成 256 色 PNG（保留透明）。
6. **命名**：按合集图里的顺序（从左到右、从上到下）对应你给的名字列表，例如 `seagull, shell, starfish…`。
7. **输出**：`pkg-beach/assets.js`（base64 + 宽高），另外在 scratch 目录生成一张检查用的拼图，方便逐个检查抠图效果。
8. **体积统计**：打印每个素材的大小和总量，超过预算时报警。

纸胶带、便签纸走同一个脚本，只是不加白描边。背景纸纹单独处理：裁成方形 → 用镜像混合消除平铺接缝 → 存 JPG。

## 3. 渲染引擎改动

| 能力 | 配置 | 说明 |
|---|---|---|
| 素材分包加载 | 风格 `assetPack: 'beach'` | `core/styleAssets.js` 渲染前 `require.async` 分包，把素材注册进图片表（键名 `pack:beach:seagull`）；加载失败时不画素材，退回纯色 |
| 贴纸小装饰 | `ornaments.small: [{ type: 'sticker', names, size: [180, 320], rotate: 12, weight }]` | 复用现有的「候选装饰位 + 避开照片和文字 + 逐级缩小」摆放逻辑；同一跨页不重复；贴纸带柔和投影 |
| 压在照片边上的贴纸 | `frameDecorations: [{ type: 'stickerOnFrame', names, chance }]` | 本页最大的照片的某个角压一张贴纸，一半露在外面（像参考图里压着照片的海鸥） |
| 图片纸胶带 | `frameDecorations: [{ type: 'tape', images: ['tapeStripe', …] }]` | 现有胶带的位置逻辑不变，把画出来的色块换成真实纸胶带图 |
| 便签纸 | `ornaments.small: [{ type: 'note', images, text }]` | 撕边便签纸放在留白处，上面可以写短句或地点日期（复用撕纸条的文字逻辑） |
| 纸纹背景 | `background: { type: 'image', src: 'pack:beach:paper', repeat: 'tile' }` | 已有的图片背景能力，改为从分包素材读取 |
| 撕纸边照片框 | `photoFrame: { edge: 'torn' }`，或版式单独指定 | 代码生成毛边（每张照片的毛边稳定不变），白色纸芯和投影；点击检测仍按矩形 |

缩略图、编辑页、预览、PDF、保存图片都走同一个 `renderPage`，所以都能显示素材。

## 4. 「大海沙滩」风格设计

- **配色**：奶油沙色底 `#F4ECDF`、雾蓝 `#7E9DB5`、海水青 `#5E9C9A`、珊瑚橘 `#E08E6D`，文字深海蓝 `#2D4356`
- **背景**：奶油色水彩纸纹平铺
- **照片**：白边 + 轻微倾斜 + 真实纸胶带；满版和大图使用撕纸边
- **贴纸**：每跨页 2–3 张，至少有 1 张压在照片边上
- **文字**：手写体西文标题（MZ Caveat），比如 Ocean Air、Salt & Sun、Sandy Toes；小号衬线写地点和日期
- **偏好版式**：叠压、小图 + 大留白、满版出血、跨中缝

## 8a 实现记录（2026-10-20）

- **素材**：用户用 ChatGPT 生成 5 张图，放在 `图片素材/海边/`（已加入 `packOptions.ignore`，不进小程序包）。汽水瓶是可口可乐经典曲线瓶的瓶形（注册商标），没有使用。最终素材：贴纸 17 个、纸胶带 3 条、便签纸 2 张、燕尾夹 1 个、纸纹 1 张。
- **处理脚本**：`scripts/build-stickers.py` + `scripts/packs/beach.json`。贴纸长边 ≤ 520px（加白边前），256 色 PNG；纸纹 1024px JPG。图片合计约 990KB，`pkg-beach/assets.js` 约 1322KB（分包上限 2MB）。
- **引擎**：
  - `core/render/assetPacks.js`：加载素材分包。
  - `core/styleAssets.js`：先根据装饰计划算出本跨页用到的素材，只加载这些（不常驻，换跨页时随照片一起释放）。
  - `core/render/stickers.js`：贴纸、照片角贴纸、图片纸胶带、便签纸（可加燕尾夹）。
  - `core/render/tornEdge.js`：撕纸边照片。
  - `core/render/wash.js`：水彩晕染大装饰。
  - `ornaments.js`：新增小装饰 `sticker`、`note`，照片角贴纸 `frameSticker`。贴纸和便签纸完整收在页内。
- **方案外的新增**：水彩晕染。代码生成，多层变形团块，边缘积色，内部有颜料颗粒，衬在本页最大照片的一角下面。第一版预览里页面偏空，参考图大量用了这种淡彩底，所以补上。
- **离线预览**：Node + @napi-rs/canvas 调用真实渲染代码。示意照片是从参考图裁出来的（他人作品），预览图只在本地看，不放进仓库。旧的 23 套模板渲染结果不变；素材分包缺失时不会报错。
