# 阶段 7c 方案：场景剪影、印章、几何纹样与装饰规则

> 目标：现有模板结构不变，让页面更丰富。新增三类装饰引擎（场景剪影、印章、几何纹样），加一层「跨页装饰规划」统一控制数量和不重复，并分配到 7 个风格。
> 本阶段**不做**：撕纸条、行李吊牌、大号描边数字（以后再做）。
> 开工前请先提交 7b（真机测试通过后），7c 改动面较大。

---

## 0. 需要你确认的点

1. **「人文建筑」目前没有这个风格。** 现有 22 个风格里没有人文建筑，只有 `architecture` 主题标签。
   - 建议：新增一个主题风格 `heritage`「人文建筑」，石灰白 + 黛青 + 朱红，放进模板页的主题组，风格总数变成 23 个。
   - 另一种做法：不新增风格，把这套装饰分配给「黑白」(mono) 或「杂志」。
2. **中式方印只用中文地名。** 地点里有英文字母（如 Kyoto）时不画方印，改由护照章出现，因为系统字体排竖排英文不好看。
3. **大装饰会跳过放不下的跨页。** 满版、跨页大图这类没有空白区的跨页不画大装饰，只画小装饰。如果硬画，就会压在照片上。

## 1. 场景剪影（新文件 `core/render/scenery.js`）

### 种类
| 种类 | 画法 |
|---|---|
| 山脉 `mountains` | 中点位移法生成折线峰顶，前景层更尖、更低 |
| 树林 `forest` | 一排三角形 / 圆冠树。高度、间距随机，前景层树更大 |
| 海浪 `waves` | 多段正弦叠加的波浪线，前景层振幅更大，可加一道浪花白边 |
| 城市天际线 `skyline` | 高低不一的矩形楼，偶有尖顶、阶梯顶、天线，远层楼更矮更密 |
| 丘陵 `hills` | 少量控制点的平滑贝塞尔曲线，起伏平缓 |

### 规则
- **种子与连续性**
  - 种子为 `spreadId + 种类`，同一跨页每次渲染完全一致。
  - 剪影按整个跨页（2160 宽）生成，左右页各取一半，跨过中缝也是连续的山。
- **分层与配色**
  - 2–3 层，由浅到深（远淡近浓）。
  - 颜色从风格配色自动计算：取风格指定的颜色键（默认 `accent`），先向背景色混合，再降低饱和度。
  - 三层的混合比例约为 背景 80% / 65% / 50%，最深一层也只是「明显的浅色」，不会压住页码和文字。
  - 反色跨页自动用 darkVariant 配色。
- **位置与高度**
  - 画在页面底部（`anchor: 'bottom'`，默认），也可以选留白区（`anchor: 'void'`，取页面上最大的一块无照片矩形区域）。
  - 底部剪影高度为页高的 14%–26%，并按本页最低照片框的位置自适应：照片下面空多少，就在空出的高度里取。
  - 剪影画在照片之下（装饰层），即使和照片边缘稍有交叠，照片也始终在上面，不会被遮挡。
- **放不下就跳过**
  - 先算底部区域被照片覆盖的比例，超过 55% 的页面不画。
  - 跨页的一侧被跳过时，另一侧照常画，在中缝处收住。
- **配置写法**
  ```js
  { type: 'scenery', kinds: ['mountains', 'forest', 'hills'], layers: [2, 3], color: 'accent',
    mix: [0.8, 0.65, 0.5], desaturate: 0.4, height: [0.14, 0.26], anchor: 'bottom' }
  ```

## 2. 印章（新文件 `core/render/seals.js`）

### 2.1 中式红色方印
- **内容**：只取 `{location}` 里的汉字，过滤空格和英文字母。
  - 超过 4 个字时，依次去掉末尾的「市 / 省 / 县 / 区 / 自治州」；仍超过 6 个字只取前 6 个。
  - 地点为空，或含英文字母，就不画。
- **排列**：从右到左竖排，右列先读。
  | 字数 | 排法 |
  |---|---|
  | 1 | 单字居中 |
  | 2 | 单列竖排（长方印） |
  | 3 | 右列 2 字，左列 1 字拉长 |
  | 4 | 2 × 2 |
  | 5–6 | 3 列 × 2 行，从右往左 |
- **字体与刻法**
  - 用系统衬线粗体。汉字没法做字形路径，体积太大。
  - 随机选两种刻法之一：白文（红底白字）或朱文（红框红字）。
  - 用「正片叠底」盖在页面上，有印泥渗进纸里的感觉，iPhone 已验证 multiply 可用。
- **做旧斑驳**
  - 外框用带抖动的折线画，四角略圆、不完全方正。
  - 印面上随机洒 30–60 个大小不一的小斑点，以及 2–3 道细划痕，颜色取页面底色，看起来像漏印。
  - 不用 `destination-out` 挖空：它会把页面背景一起挖穿。
  - 整体轻微旋转 ±4°，透明度 0.85–0.95。
- **配置**：`{ type: 'seal', size: [110, 150], color: '#B83A2E' }`，size 为基准 px。

### 2.2 护照入境章
- **外形**：随机选一种。
  - 圆角方形
  - 椭圆，用贝塞尔路径，不依赖 `ctx.ellipse`
  - 圆形，文字沿弧排列，复用明信片邮戳的弧形文字代码
- **内容**
  - 双线外框，内含三行：地名（大写；中文地名用系统字体）、日期（`18 OCT 2026`，取开始日期）、`ARRIVED`。
  - 偶尔改成 `ENTRY`，并加一个小飞机或箭头线稿。
  - 地名为空时省略这一行，日期为空时省略日期，`ARRIVED` 始终有。
- **叠压**
  - 一组 1–3 个，彼此错开 30%–50% 叠压，各自旋转 ±18°。
  - 透明度 0.55–0.8，用正片叠底。
  - 颜色从风格的 `stampColors` 里轮换，默认为低饱和的蓝、红、绿、紫。
  - 墨色有浓淡：用和方印同样的斑点法做缺墨。
- **配置**：`{ type: 'passport', count: [1, 3], size: [150, 210], colors: [...] }`

## 3. 几何纹样库（新文件 `core/render/patterns.js`）

### 纹样
| 名称 | id | 画法 |
|---|---|---|
| 青海波 | `seigaiha` | 一排排同心半圆错位叠放 |
| 回纹 | `meander` | 连续回字折线，适合做页边条 |
| 麻叶 | `asanoha` | 六角星形放射线网格 |
| 七宝 | `shippo` | 互相交叠的圆，形成花瓣格 |
| 波点 | `dots` | 交错排列的圆点 |
| 条纹 | `stripes` | 等距斜纹或直纹，可设角度 |
| 方格纸 | `grid` | 细方格，每 5 格一条粗线 |
| 点阵 | `dotgrid` | 点阵手账纸 |
| 横线信纸 | `lined` | 横线，可加一条左侧红色竖线（边距线） |

### 画法与用途
- **画法**
  - 全部用矢量路径直接画，不依赖图片，在 1080 宽和 2480 宽下都清晰。
  - 每种纹样合成一条 path，一次性 stroke 或 fill，性能可控。
  - 先 clip 到目标区域，再按 `cell`（基准 px）铺满。
- **三种用途**（同一套函数，换个区域即可）
  1. **整页底纹**：`background.pattern = { name, color, alpha: 0.06–0.12, cell }`，画在底色之上、照片之下，对比度很低。
  2. **色块填充**：版式 blocks 和装饰 rect 可以加 `pattern` 字段，色块里叠一层纹样（如桌布色块上叠条纹）。
  3. **页边装饰条**：`{ type: 'patternBand', name, edge: 'outer' | 'top' | 'bottom', width, color }`，如回纹、青海波页边。
- **配置示例**
  ```js
  { type: 'patternBlock', name: 'seigaiha', x, y, w, h, color: 'accent', alpha: 0.35, cell: 60, mirror: true }
  ```

## 4. 装饰规则：跨页装饰规划（新文件 `core/render/ornamentPlan.js`）

现在每类装饰各自按 `chance` 决定是否出现，数量不可控，线稿也可能重复。改为每个跨页先算出一份「装饰计划」，左右页渲染时都读同一份计划。

### 风格配置
```js
ornaments: {
  big:   [ { type: 'scenery', kinds: [...], weight: 3 }, { type: 'patternBlock', name: 'stripes', weight: 1 } ],
  small: [ { type: 'doodle', weight: 3 }, { type: 'seal', weight: 1 }, { type: 'passport', weight: 1 } ],
  smallPerSpread: [2, 3],
  pageTypes: ['body']
}
```

### 规划步骤（全部按 spreadId 稳定随机）
1. **大装饰（1 个）**
   - 按权重选一个，先检查是否放得下（剪影看底部覆盖率，纹样色块看指定区域是否压照片）。
   - 放不下就换下一个候选，全部放不下则本跨页没有大装饰。
   - 大装饰放在左页还是右页，或横跨两页，由种类决定：剪影和页边条横跨两页，色块放在一侧。
2. **小装饰（2–3 个）**
   - 按权重抽类型。同一跨页里方印最多 1 个，护照章最多 1 组（一组可以是 1–3 个叠压）。
   - 位置沿用现有线稿的候选装饰位，避开照片、文字槽、大装饰区域。
3. **线稿不重复**
   - 本跨页要用的线稿名，从风格 `doodles.names` 洗牌后按顺序取，不放回。
   - 照片角线稿（cornerDoodle）和邮票里的线稿也从同一个列表里扣除。
   - 候选不够时宁可少画，也不重复。
4. **兼容**
   - 没写 `ornaments` 的风格保持原样，不受影响。
   - 写了 `ornaments` 的风格，原来的 `doodles.perSpread` 不再单独决定线稿数量，由小装饰配额统一分配。

### wordPool 整本书不重复（改 `core/album.js getPageList`）
- 只有版式里真有 `{word}` 文字槽的跨页才消耗一个词。现在没有标题槽的跨页也会占用一个词。
- 每个风格各自记录已用的词，按跨页 id 在未用的词里稳定选取。
- 词用完后整池重来，并保证不和上一个重复。按现有 41 个正文版式里标题槽的出现频率估算，20 跨页的书一般用 6–10 个词。
- 所有带 wordPool 的风格（14 个，加上人文建筑共 15 个）补到 **每池 20 个以上**，和现有词的口吻保持一致。

## 9. 实现记录

### 已确认 / 采用的默认决定
- **新增「人文建筑」`heritage`**：主题组，石灰白 + 黛青 + 朱红，方印为主角。风格总数变为 **23**（纯色 8 / 风格 9 / 主题 6）。
- 中式方印只用中文地名，地名含英文字母时不画。
- 放不下的跨页跳过大装饰。

### 和方案不同的地方
- **留白区剪影没做。** 剪影只放在页面底部（`anchor: 'bottom'`），`anchor: 'void'` 没有实现。底部已经够用，留白区还会和标题槽抢位置。
- **伪随机数修复。** `hashRandom`（FNV-1a）缺少末尾的雪崩混合，只差最后一个字符的 key 得到的值几乎一样，例如 `type:0` 到 `type:7` 的结果是 0.911、0.908、0.904……，按权重抽取严重偏向同一个结果。已在 `frames.js` 末尾加上 murmur3 fmix32。
  - **影响全部风格**：照片随机倾斜角度、线稿位置、装饰词选择都会和之前略有不同（仍然是稳定的）。相册不持久化，所以没有兼容问题。
- **印章自动缩小。** 放不下时依次缩到 80%、65% 再找位置；线稿只试原尺寸。
- **深色页的墨色。** 反色跨页上，印章和护照章改为普通叠加：正片叠底在深色底上会看不见。
- **候选装饰位。** 新增 4 个半页留白处的位置，上角两个下移到 y = 170，避开页眉。
- **线稿全局去重。** 没写 `ornaments` 的风格也按跨页去重：线稿名不放回地取，照片角线稿、邮票线稿也算在内。
  - 自然风光的照片角线稿加了 `flower`，这样左右页可以各有一个。

### 各风格的配置
- **大装饰从 decorations 移进了 ornaments.big。** 原来按 `chance` 出现的装饰都换成了大装饰候选：
  - 杂志的赤陶色块，现在叠条纹或波点。
  - 明信片正文页的航空斜条。
  - 美食正文页的格纹页边。
  - 封面上的这些装饰不变。
- **词池。** 全部 14 个有词池的风格都补到 20 个以上（胶片风格没有标题槽，不用词池）。只有版式里有 `{word}` 文字槽的跨页才用掉一个词。
