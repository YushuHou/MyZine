# 阶段 6 方案：设计引擎升级 + 纯色系列 + 3 个招牌风格

> 确认日期：2026-10-17。依据：需求文档「阶段 6 详细需求」（2026-10-17 更新）。

## 已确认的决定
1. 字体：Playfair Display、Caveat、Oswald，从 Google Fonts 官方 GitHub 仓库下载（仅开发时联网），子集化后转 base64 放分包，OFL 授权文件随字体放进项目。
2. 基础库 3.17.4 满足 Data URL 字体（≥ 3.7.9）的要求；更老版本退回系统衬线体。
3. `{month}` 用英文月份名（如 July）。
4. 照片编号整本书连续。
5. 安卓先记为「未测试」，用户找到安卓机后补测。
6. 满版出血版式允许贴中缝。
7. 开发页（验证页、线稿预览页）：按环境隐藏入口 + 开关配置；README 写明提审前从 app.json 移除开发分包。

## 0. 先核实的结论（官方文档）
- `wx.loadFontFace`：`source` 只能是 **https 链接或 Data URL**（Data URL 需基础库 **3.7.9**）；`scopes` 含 `native` 才能用于 **Canvas 2D**；文档未提及本地路径 / 代码包路径。
- 小程序纯本地、不联网 → 字体只能以 **base64 Data URL** 提供。
- 5b 已验证：画布、文件接口都**读不到分包里的图片文件**；但分包里的 **JS 模块** 可用 `require.async` 加载（基础库 2.11.2+）。
- 因此统一的素材方案：**字体（以及今后的图片素材）转为 base64，写成分包里的 JS 模块，`require.async` 加载**。

## 6a-0 验证结论（2026-10-17，iPhone 16 Pro Max / iOS 18.7.7 / 微信 8.0.79 / 基础库 3.17.4）
| 项目 | iPhone 真机 | 开发者工具 |
|---|---|---|
| 主包 `require.async` 分包 JS | ✅ 首次约 0.8–3.5 秒（下载分包），之后毫秒级 | ✅ |
| `wx.loadFontFace`（Data URL，scopes native + webview）注册 | ✅ | ✅ |
| 页面普通文字使用该字体 | ✅ | ✅ |
| **canvas 2d（页面画布 + 离屏画布）使用该字体** | ❌ 不带引号 / 带引号 / 完整声明均无效，等待 1.5 秒仍无效，宽度与默认字体相同 | ✅ |
| 画布加载 Data URL 图片 | ✅ | ✅ |

- 结论：**iPhone 上 Data URL 注册的字体不能用于 canvas 2d**（字体数据与注册均正常，页面文字已生效，是原生画布不识别）。开发者工具用的是浏览器画布，结果不可作为依据。
- 安卓：未测试。
- 推论：图片素材可以用「base64 写入分包 JS 模块 + `require.async` + Data URL 图片」的方式提供（已验证）。
- 西文字体改用 **字形路径方案**（待用户确认）：用 fonttools 把子集字体的字形轮廓导出为 SVG 路径数据（含字宽、字距对），存入分包 JS 模块；用 6a-3 的 SVG 路径绘制器在画布上直接绘制。页面画布、离屏画布、打印版完全一致。OFL 保留名称条款：转换后的数据使用 MZ 前缀名称并注明来源，附授权文件。限制：不保留 Caveat 的连写替换字形；仅用于西文短文本，中文仍用系统字体，混排时同一基线衔接。

### 字形路径方案已确认（2026-10-17）
- MZ 前缀命名（MZ Playfair / MZ Caveat / MZ Oswald），注明来源，附 OFL 授权文件。
- **中西文混排规则**：中西文混排的标题尽量分行。例如海边明信片「Greetings from {location}」：第一行「Greetings from」用 MZ Playfair 字形，第二行 {location} 单独一行，用较大字号的系统衬线字体。只有短的组合（如页眉「{location} · {date}」）才在同一行混排，并保证基线对齐。

## 6a-1 照片形状
- `frame.shape`：rect（默认）/ rounded / circle / ellipse / arch（上半圆下矩形）
- 统一的形状路径函数，裁切、边框（外形填边框色，内缩形状裁照片）、阴影、点击检测（按形状判断点是否在内）共用；拖动缩放仍按外接矩形换算
- 拍立得加宽底边只用于 rect / rounded；circle 取内切圆（标注为方框）

## 6a-2 装饰文字层
- **位置由版式定，内容和字体由风格定**：
  - 版式页面可声明文字槽 `slots: [{ type: 'headline' | 'kicker', x, y, w, align }]`（放在留白区）
  - 风格声明各类型的内容与样式 `decoText: { headline, kicker, runningHeader, pageNumber, index }`；风格没定义的类型不画
- 类型：headline（大标题）、kicker（小号加宽字距大写副标题）、runningHeader（页眉 + 细线）、pageNumber（两位数 07）、index（照片编号 01、02…）
- 变量：`{title} {location} {date} {year} {month} {word}`；任一变量为空则整条隐藏
- `wordPool`：按跨页 id 哈希稳定选取，相邻跨页不重复（整本书顺序计算，页对象带 `word`）
- 大写只作用于西文字母，中文原样
- 页眉、页码、照片编号被照片盖住时不画（风格声明 `overPhoto: true` 的除外）

## 6a-3 线稿库
- `templates/doodles/`：每个线稿 `{ viewBox, paths: ['M…'], mode: 'stroke' | 'fill' }`，我手绘路径数据
- 轻量 SVG 路径解析器 `core/render/svgPath.js`：M/L/H/V/C/S/Q/T/A/Z（含相对坐标），A 转贝塞尔；描边宽度按画布宽度换算
- 第一批 13 个：星星、闪光、爱心、云朵、音符、花朵、枝叶、箭头、波浪线、贝壳、太阳、海鸥、邮戳圆环
- 线稿预览页 `pages/dev/doodles`：网格列出全部线稿（不同尺寸、描边 / 填充），仅开发版可见
- 摆放：页面候选装饰位（四角、外侧页边中部、留白区），剔除与照片框重叠的位置，按跨页 id 稳定选取

## 6a-4 新版式（左右镜像、标注方向和 density）
| 版式 | density |
|---|---|
| 满版出血：一张照片铺满整页（四边，含中缝侧） | normal |
| 小图 + 大留白 + 标题槽（headline / kicker） | airy |
| 密集网格：每页 5–6 张（2×3、1 大 4 小） | dense |
| 大头贴四格条：竖向 3–4 张小方图连成一条（条底色用色块） | normal |
| 叠压：一张带白边阴影的照片叠在另一张上（照片框级别的白边阴影） | normal |
| 跨中缝：一张照片横跨中缝一部分，另一侧配小图（跨页坐标版式，可多框） | normal |
| 圆形框版式、拱形框版式各至少 1 个 | airy / normal |
- 现有 25 个版式补上 density 标记

## 6a-5 版式节奏
- 同分候选按节奏优先：不连续两个 dense；连续两个 normal 后，有方向匹配的 airy 就优先
- 反色跨页：风格提供 `darkVariant`（配色 / 背景）并开启时，自动排版约每 5 个正文跨页标记一个 `inverted`（不连续、位置稳定）；渲染时合并深色配置

## 6a-6 色块背景
- 版式页面 `background`（左右页可不同）和 `blocks: [{ x, y, w, h, color }]`
- 风格 `pagePalette`：底色在跨页间变化、左右页可不同（按跨页 id + 左右稳定选取）

## 6a-7 西文字体（视 6a-0 结论）
- 候选（均为 SIL OFL）：衬线展示体 **Playfair Display**（杂志标题）、手写体 **Caveat**（手账标题）、可选窄体 **Oswald**（粗标题）
- 用 fonttools 子集化：基本拉丁字母、数字、常用标点；总量约 300KB 以内；转 base64 写入分包 JS 模块，附 OFL 授权文件
- `app.js` 启动后异步加载（`global: true`、`scopes: ['native']`）；导出前等待字体加载完成；失败退回系统衬线体
- 中文仍用系统字体（字体栈：`"Playfair Display", serif`）

## 6a-8 纯色系列 8 种
- 纸白（id 改为 `paper`，原 `minimal` 作为别名迁移）、燕麦、雾灰、雾霾蓝、鼠尾草、深蓝、墨绿、酒红，配色按需求文档表格
- 装饰克制：页眉（地点 · 日期）、两位数页码、点缀色细线；深色三种的中缝线、页码用点缀色
- 风格增加 `group: 'solid' | 'style' | 'theme'` 和 `swatch`（小圆点颜色）

## 6b 招牌风格
- **杂志**：纸白底、衬线西文大标题（wordPool）、kicker、页眉 + 细线、页码、照片编号；偏好满版、跨中缝、小图 + 大留白；开启反色跨页；赤陶色块偶尔出现在一角
- **手账升级**：保留纸张、胶带、拍立得、倾斜；每跨页 2–4 个线稿；粉 / 奶油 / 浅棕底色在跨页间变化、左右可不同；偏好四格条、叠压；手写体西文标题
- **海边明信片**：海蓝 + 沙色；波浪线、贝壳、太阳、海鸥；明信片框（白边 + 右上邮票框 + 邮戳圆环，环内沿圆弧写 {location}/{date}，为空只画圆环）；航空信封红蓝斜条页边；标题「Greetings from {location}」（无地点时「Greetings」）；偏好圆形框、满版
- 风格可声明「偏好版式」：自动排版时这些版式权重提高
- **模板页分组**：纯色 / 风格 / 主题（主题组阶段 7）；纯色组用色块小圆点切换，其余用示例跨页

## 6a 实现记录（2026-10-17）
- **字形路径**：`scripts/build-glyphs.py` 生成三套字形数据（各 105 字形；字距对 Playfair 1680 / Caveat 916 / Oswald 884），合计约 221KB，放 `pkg-fonts` 分包；`core/render/svgPath.js`（M/L/H/V/C/S/Q/T/A/Z，A 转贝塞尔）+ `core/render/glyphText.js` 绘制，中西文同一行基线对齐。原 TTF base64 移到 `dev/check/ttf/` 仅供验证页对照。
- **照片形状**：rect / rounded / circle / ellipse / arch；裁切、边框、阴影、选中描边、点击检测（`pointInShape`）共用 `core/render/frames.js`。拍立得加宽底边只用于矩形类。版式里 `border: false` 的框（如四格条）不随风格倾斜、不贴胶带。照片框可带 `mat`（叠压用的白边阴影）。
- **装饰文字**：`core/render/decoText.js`。版式页 `slots` 定位置，风格 `decoText` 定内容（headline / kicker / runningHeader / index）；页码在 `pageNumber`（`format: 'pad2'`、`glyph`）。变量为空整条隐藏；`word` 由 `getPageList` 按跨页 id 稳定选取且相邻不重复；照片编号整本书连续（页对象 `frameNumbers`）。页眉、编号被照片盖住时不画。
- **线稿库**：`templates/doodles/index.js`（13 个，viewBox 0 0 100 100）+ `core/render/doodles.js`（绘制、按风格 `doodles` 配置在 8 个候选装饰位中避开照片和文字摆放）。开发分包新增「线稿与字形预览」页。
- **新版式**：共 39 个正文版式（+14）：满版出血、标题 + 小图（带文字槽）、六宫格、五图、大头贴四格条（色块纸条）、叠压、圆形、拱形、跨中缝（跨页坐标多框）；全部标注 density（normal 26 / airy 9 / dense 4）。版式选择面板显示圆形、拱形。
- **节奏**：同分候选先看节奏（不连续 dense；两个 normal 后优先 airy），再按权重轮换；风格可用 `layoutWeights` 提高偏好版式。第 5、10、15… 个正文跨页标记 `inverted`，风格有 `darkVariant` 时使用深色版本。

- **纯色系列**：`templates/styles/solids.js` 8 种，`group: 'solid'`、`swatch`；页眉（地点 · 日期 + 点缀色细线）、两位数页码（MZ Playfair）；深色三种页码 / 页眉 / 中缝细线用淡金。原 `minimal` 删除，`registry` 中作为 `paper` 的别名。
- 包体积：主包代码约 236KB；字体分包约 236KB；开发分包约 185KB（提审前移除）。
