# 阶段 8g：温馨时刻（家庭主题，不画人物）

> 2026-10-20。用户把「欢乐一家」改名为**温馨时刻**（id `family`）。素材原图在 `../MyZine素材/家庭/`，提示词见 `阶段8-素材提示词.md` 第 3 节。

## 素材（`pkg-family` 约 1.6MB）
- 贴纸 18 个，分三组：
  - 动物一家：熊、鸭子、长颈鹿、狐狸、大象、企鹅
  - 出游物件：风筝、气球、玩具拖车、帐篷篝火、野餐篮、旋转茶杯
  - 温暖小物：小房子、向日葵、彩虹、四双鞋、小熊、生日蛋糕
- 纸材：黄格纹、彩色波点、天蓝纸胶带；黄色方格便签、云朵便签；红色燕尾夹。背景是暖奶油水彩纸纹。
- 「四双鞋」里最小那双和其他鞋之间间距较大，白描边分成了两段。不影响使用。

## 复用
- 自然风光：草地小丘剪影（`scenery: hills`，草绿色）。
- 美食：野餐格纹页边（`checkerBorder`，只画底边，苹果红）。
- 心动旅程：飘落的小爱心（密度更低）。
- 大海沙滩：邮票（里面是小房子、彩虹、企鹅等）+ 邮戳。封面问候语是「Family Trip to {location}」，没有地点时写「Family Time」。
- 公路旅行：行李吊牌。

## 配色
- 主色调在天空蓝、向日葵黄、草绿之间轮换。苹果红只用在格纹页边、吊牌这类小点缀上。
- 偏好版式加入了多图版式（双图、四宫格、四格条），因为家庭照片通常比较多。
